## v0.3.0：靛蓝采石场更新（2016-04-13）

> 官方推荐的存档兼容策略：建议新档体验，但 0.3.0 之前的存档仍兼容（今后不保证）；旧档可能卡进新几何体（如山体）——用选项菜单的紧急返回即可。

**新区域：靛蓝采石场**
新增可探索区域，洞窟与峭壁纵横交错，因稀有矿物而带有深紫色调；曾是采矿项目旧址，因稀有矿石离开致远牧星大气即快速分解而倒闭。采石场使可探索空间增加约 50%。

**新史莱姆：辐射史莱姆**
可从靛蓝采石场驯养。辐射结晶相当值钱，但需小心辐射病——进入辐射光环后辐射计开始累积，满值后继续暴露会受伤；远离一段时间即可消退。

**新史莱姆：招财史莱姆**
稀有史莱姆，喵喵史莱姆的奇特变体，痴迷闪亮物体（尤其是新币）。会吞下遇到的硬币，走动时叮当作响。想拿到它圆鼓鼓肚子里的新币？想不出办法就问鲍勃。

**新蔬菜：欧卡薯**
致远牧星烹饪的主食，天然咸味、口感软糯的土豆；是"牧场主薯饼"的关键食材。可在采石场找到。

**新模式：五日快攻**
新增游戏模式（标准体验现在叫「冒险」）：5 天内尽量赚取新币。规则：第 1 天 9:00 开始、第 6 天 12:00 结束（5 天 3 小时）；结束时弹出计分窗口可截图分享；每天交易所的当日委托必给 3 个黄金结晶；结晶市场不波动；初始 500 新币；死亡只推进时钟 1 小时但扣 10% 新币；进小屋仍暂停时间，但快攻中无法看星际邮件。

**新功能：水槽**
可购买，是收集淡水的唯一途径（水槽只能存水）。旧档水槽里其他储槽的水会被移除。水槽随其他真空储槽一起升级。

**水滴史莱姆改动**
图形重做，更"水滴"了；天性害羞现在体现在行为上——附近超过 3 只史莱姆（不论种类）就不产结晶；另外它发现自己被真空枪射出时很像飞盘……你怎么用这条信息随你。

**其他新功能**：
- 新增史莱姆百科条目（含补全部分鸡的条目）
- 标题菜单显示存档更多信息，可设新档图标（理论上你能选水滴史莱姆以外的图标，但何必呢）
- 新增制作人员名单界面
- 在仓储塔/结晶市场/自动喂食器/结晶收集器附近射击与吸取，片刻后会加速
- 可切换真空枪握持方式（抓大型物体如板条箱/大型史莱姆时）；「启用真空枪切换握持」会锁定物体直到再次按射击/吸取（类似《半条命 2》和《传送门》，默认开启）
- 致远牧星各处出现巨型嶙峋山脉（美化地平线 + 限制捷径/卡位；看到山挡路就绕道，别想着翻过去）
- 巨型史莱姆更"巨型"了，视觉效果升级
- 火把有摇曳火焰
- 远景分阶段加载，可加载更远的远景
- 音乐夜间变奏从 18:00 开始（目前仅牧场与岩礁支持）
- 启用 Steam 云存档（Mac 存档路径变更，自动迁移）
- 新增 Steam 徽章与集换式卡牌
- 丰茂原野与幽暗山洞新增双向传送器（但挡路的巨型史莱姆要先解决）

**平衡调整**：部分真空枪升级与两个牧场扩张涨价；喷气背包空中能量消耗调整（连续点按比持续喷射更耗能，移除"喷气背包飞超远"的漏洞）

**美术打磨**：大型史莱姆/板条箱被抓住时透明度改进；设施/扩张/升级新图标；其他牧场主新头像；牧场数字显示屏新增 LED 效果（"像素里藏着什么秘密？嘘——"）；园地升级新模型动画；地面/峭壁/树木纹理改进；史莱姆嘴部渲染加深（还在读吗？）；史莱姆受光高光质量提升；草丛动画改进；花朵细节增加（还在读？我们在讲花）；炸弹爆炸特效改进；焦油怪死亡新特效（"棱镜般充满欢乐，因为死亡中也要庆祝焦油怪的一生"）；受伤指示新特效；水槽满时镜头水花特效
