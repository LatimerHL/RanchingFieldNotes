# 大地图识别（一代 · 远、远牧星）

> 来源：游戏内地图数据节点实测坐标（fandom 交互地图，图幅 3987×2971、原点左下）+《史莱姆百科》世界条目 + 社区全景拼图（Napalm_Isis / HopperLabs 版）
> 用途：回答「地图上 XX 旁边 / 左边那块岛是哪里」这类问题，避免把独立岛套成主大陆区域名。

## 结论先行（易错点）

- 玩家口中的「琉璃沙漠 / 玻璃沙漠」＝官方简中**玻璃荒漠（Glass Desert）**。
- **玻璃荒漠左侧（西侧）那座黄色小岛＝奥格登的别墅（Ogden's Retreat）**，不是古代遗迹。（2026-11-07 发明者核定；此前在频道求助里误答成古代遗迹）
- 古代遗迹在主大陆最北端，是米黄／土黄阶梯建筑＋水渠＋浅绿台地，与玻璃荒漠之间隔着传送器，并不在荒漠旁边。
- 游戏内地图**不显示**奥格登的别墅、荒蛮群岛、莫奇庄园、迅捷峡谷（位置显示 Unknown），只能靠传送器到达；能"看见"它们的只有社区全景拼图。
- 拼图里**维克多的工作间＝海面上一个孤立黑色建筑图标**（方形舱体＋绿色方框入口＋两只紫色史莱姆头像）；它下方那片迷你大陆是**史莱模**（虚拟致远牧星的缩略复刻），不是工作间本体。（2026-11-08 发明者核定）

## 一、两套地图别混用

| | 游戏内地图（Map of the Far, Far Range） | 社区全景拼图（Napalm_Isis / HopperLabs 等） |
|---|---|---|
| 内容 | 主大陆各区域 + 玻璃荒漠；独立岛显示 Unknown | 把所有区域按实际／近似位置拼成一张图，独立岛也能看到 |
| 比例 | 区域按设计排列，非真实地理 | 非官方比例，只适合辨认"哪块是哪个区域" |
| 什么时候用 | 玩家问"游戏里怎么走、地图节点在哪" | 玩家问"这张大地图上 X 旁边那块是哪里" |

## 三、独立区域

| 区域 | 到达方式 | 在拼图上的样子 |
|---|---|---|
| 奥格登的别墅（Ogden's Retreat） | 解锁被苔岛大门＋购买丰茂原野＋与奥格登完成交易 → 牧场与丰茂原野之间的传送器 | 黄色／橙黄小岛，带围栏菜圃、小水池、粉红库卡多巴树和奥格登的个人交易所；**在玻璃荒漠左侧** |
| 荒蛮群岛（The Wilds） | 从奥格登的别墅的传送器进入；离开要找到 3 个单向传送器之一 | 一组古代岛屿，狂暴剑齿大型史莱姆＋库卡多巴果 |
| 莫奇庄园（Mochi's Manor） | 解锁靛蓝采石场大门＋购买山洞＋与莫奇完成交易 → 山洞入口传送器 | 带菜圃的庄园；资料记为牧场与 Ring Island 以南 |
| 迅捷峡谷（Nimble Valley） | 完成莫奇委托后由莫奇庄园的传送器进入 | 资料记为在莫奇庄园左侧 |
| 环礁岛（Ring Island）／小胡子岛（Moustache Island）／灰烬岛（Ash Isle） | 传送器、海边小岛 | 主大陆西南角、西侧中部等零散小岛 |

> 「以南／左侧」来自 fandom 页面说明。二创拼图上各独立岛的位置见第六节（2026-11-08 按图形与地形逐块核对）。

## 四、读图速查（颜色 → 区域）

- 橙红干燥岩礁＝干涸岩礁；深绿丛林＝被苔岛；紫色／靛蓝岩层＝靛蓝采石场
- 米黄／土黄阶梯＋水渠＋浅绿＝古代遗迹
- 粉红岩壁＋黄沙＋粉色玻璃晶柱＝玻璃荒漠
- 小块菜圃方格＝牧场（或其扩建区）；黄色小岛＋围栏菜圃＝奥格登的别墅

## 五、回答纪律

1. 先判断是哪张图：游戏内地图（独立岛是 Unknown）还是社区拼图（独立岛可见）。
2. 只按颜色＋形状＋相邻关系匹配，不凭"听起来像"套区域名。
3. 独立岛不要套主大陆区域名（奥格登的别墅 ≠ 古代遗迹）。
4. 拿不准就说清"本姆看这张图分不出来"，请对方发截图或说明图源。
5. 引用社区拼图时点明"非官方比例"，避免玩家按它算距离。
6. 维克多的工作间 ≠ 史莱模：工作间是独立设施（海面/海底图标），史莱模是其中的虚拟致远牧星系统；拼图上那块迷你大陆只代表史莱模。
