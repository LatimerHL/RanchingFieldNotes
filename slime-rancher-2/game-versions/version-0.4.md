## v0.4.0：随心所置（2024-02-08，官方 PST；北京时间 2024-02-09）

> 官方定性：今年首个内容更新为《史莱姆牧场 2》的装置系统带来革命性变革。发挥创意，用一系列全新装置点缀彩虹岛——它们既别致，又充满惊喜，还带点蠢萌。既可以把彩虹岛变成史莱姆的梦幻绿洲，也可以从头到尾翻新牧场，或者向岛上的居民展示一场机械化的混乱秀。

**新内容概览**：
- 史莱姆交互升级：新增生动而富有想象力的史莱姆交互。想象史莱姆们在沙滩上闲逛、在自制弹珠机里畅玩、在缤纷风车之间欢跃；从宁静到欢乐的各种主题氛围，让玩家能与史莱姆共创许多美好回忆
- 全面改进的建造系统：装置模式 HUD 更加直观，并新增一套集成进新版史莱姆百科的收集回顾系统；既能更轻松地搭建理想牧场，也提升了探索、记录独特史莱姆与装置词条的乐趣
- 更多装置内容与探索：共有 36 种全新装置和宝藏在彩虹岛的隐秘角落等待发掘；寻找隐藏藏宝球、收集设计图，点亮这些新装置

**装置系统全面升级**：
- 取消装置放置限制，拾取装置时装置不再销毁；现在可以随心所欲地放置装置，只要为大件装置留出足够空间
- 不必返回制造器即可浏览装置库存；新增收藏栏，方便快速切换最常用的装置；装置分类也已更新
- 部分原有的放置快捷键有变化；官方表示经过数月严格测试，新系统在长期操作导航上更优，请玩家容忍这次更新带来的小幅学习曲线
- 在世界各处新增若干装置供探索者发现：四处搜寻这些隐藏珍品，收集设计图，制造新的装置

**世界更新**：
- 所有区域都加入了小幅扩张，世界因此更加广阔、也更有意思；官方期待玩家用这些新装置在这些空间里发挥创意

**UI 改进**：
- 在开始界面新增光敏性癫痫警告，面向对光敏感的玩家；官方表示正在研究更多无障碍改进并将在未来更新中加入
- 新增通讯站消息的 HUD 提示
- 制造器图标进行了美化
- 修改了制造器中真空枪升级的指示器显示

**地图改进**：
- 更新地图光标
- 更新地图的艺术风格
- 更新藏宝球计数器
- 更新地图以反映所有区域新增的内容

**其他一般更新**：
- 位置旗帜现在会随阵风自然摆动
- 改进了数据分析的处理与备份管理
- 优化了场景的加载与重载
- 重新组织音频与音乐文件结构
- 调整了不同语言下 UI 文本的可读性
- 改善了环境光遮蔽与景深后处理效果
- 对世界中一些现有部分的环境美术做了小幅改进

**修复**：
- 岩浆池中的火焰史莱姆不再穿模
- 史莱姆不再从「头号史莱姆展示台」装置中逃脱（官方认定这是怯场所致，于是进行了鼓舞士气的谈话）
- 选项中「输入死区」现已正常生效
- 使用 Xbox 手柄十字键打开地图时，地图不再自动关闭
- 腐烂的花岗石榴不再沉入地面（咦……）
- 焦油怪用触手抓取物品的动作现在更加稳定，官方随即自问：我们为什么要改进这种事？？？
- 修复巨型棉兔史莱姆耳朵有时显示不正确的问题
- 落粉峭壁的树木在远处不再看起来被风吹平
- 藤蔓史莱姆的藤蔓与气象藤芽现在能正确生成
- 喷出噗啦蝶史莱姆时不再产生水花特效
- 修复世界各处关于碰撞与透明度的多种问题
- 更新了一些拼写错误、翻译问题、字体加粗以及不受支持的字符

**已知问题**：
- 使用非英语键盘时，「下一储槽」的符号会显示在「上一储槽」的按键绑定上
- 将键盘类型更改为法语会在键位绑定区引发格式问题
- 已解锁落粉峭壁古代传送器的玩家，会在灰烬山谷以西看到错误的传送路径

**那接下来（后续计划）**：
- 「随心所置」之后，2024 年还计划推出两次更新：一次在 2024 年夏季，另一次目标为 2024 年秋季
- 官方表示不久后会分享更多细节

## v0.4.1：补丁说明（2024-02-29，官方 PST；北京时间 2024-03-01）

> 官方定性：本次补丁集中处理「随心所置」更新中出现的、特别让人头疼的一批 bug。

- 修复史莱姆有时会从牧栏中消失的问题
- 落粉峭壁以西的传送线路现在能在地图上正确显示
- 修复部分玩家在体力耗尽昏倒后卡死（软锁）的问题
- 修复部分玩家会在星光滨岸掉出地面的问题
- 更新制造器网格，现可正确标示新物品
- 修复使用手柄且装置快捷栏已满时，收藏栏第一格的装置会被清空的问题；你最爱的装置现在会稳稳留在第一位
- 玩家现在可以在灰烬山谷的新藏宝球中获得高大琥珀色柏树
- 修复史莱姆百科条目，现可正确显示总数 262 项

**官方补充**：如果玩家认为遇到了 bug，建议先查阅已知问题列表；列表中没有的，请务必提交工单给团队，信息越详尽越好。2024 年夏季与秋季更新的排期仍在计划内，官方也期待看到玩家用新装置系统造出的各种奇思妙想。
