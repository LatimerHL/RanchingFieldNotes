## v0.5.0：奇趣立购（2024-05-30，官方 PDT；北京时间 2024-05-31）

> 官方定性：本年第二次内容更新，引入全新的立购坊商店系统，带来大量新装置、装置变体，以及史莱姆玩具的回归。

**更新概览**：
- **在立购坊消费新币**：本更新引入全新商店系统，让辛苦赚来的新币有处可花；可前往立购坊购买设计图、玩具、温馨装饰等
- 在上一次更新的基础上，立购坊进一步助力玩家的探险与牧场经营之旅
- 商店里还有一位毛茸茸的可爱小伙伴，多多留意
- **装置变体大放异彩**：新增 51 款独特装置与 31 种装置变体，兼具实用与美观，用于个性化牧场
- **史莱姆玩具回归**：吃饱的史莱姆是快乐的史莱姆，但史莱姆也会因彩虹岛的各种压力而焦躁不安（官方点名「饥肠辘辘的焦油怪」）；玩家可通过立购坊终端购买玩具安抚它们，本次既有经典款回归，也有全新玩具

**立购坊**：
- 立购坊终端位于温室内，店内分为极星供应站与啾啾角两大区域
- **极星供应站**：出售制造装置所需的设计图
- **啾啾角**：每日特惠店，出售装饰性与功能性装置，以及逗乐史莱姆的玩具
- 每日特惠每游戏内一天更新一次，需常来查看
- 提示：玩家可在拿到设计图之前就直接获得某些物品，务必仔细探索彩虹岛，也别忘查看通讯站

**装置与装置变体**：
- 装置变体是对已有装置的改款，在颜色、材质或设计上有所变化，用于进一步个性化温室
- 玩家在选择已放置的装置时可切换其变体；变体也可在制造器与史莱姆百科中预览
- 注意：并非所有装置都有变体，且变体可能在基础版装置之前获得

## 术语修正与存疑 ⚠️

1. **water spout ＝ 官中「水坑」** ✅：发明者 2026-09-22 确认——此处的 spout 就是官方口径的「水坑」，指**一泓小泉眼**（与能把人喷上天的水柱喷泉不同）。官方原文：A new treasure pod has been added to Rainbow Fields, and a water spout has been removed (a good trade tbh)——用彩虹原野的一处水坑换了个新藏宝球；正文已改用水坑/泉眼表述
2. **极星供应站（Polestar Provisions）** ✅：B 站译文作「极星补给站」，按 terminology.md 官中改为**极星供应站**
3. **啾啾角（Coo-Coo Corner）** ✅：B 站译文前文作「啾啾角」、后文误作「咕咕角」，统一为官中**啾啾角**
4. **大型史莱姆命名格式** ✅：B 站译文在修复条目中把 Largo 名写成「蝙蝠大型史莱姆」「蝙蝠旋风大型史莱姆」等，官中格式为「大型＋主类型＋副类型＋史莱姆」，已统一改为**大型蝙蝠史莱姆、大型蝙蝠旋风史莱姆、大型猎猫旋风史莱姆、大型安康旋风史莱姆、大型粉红旋风史莱姆**（其中 Hunter＝猎猫、Pink＝粉红）
5. **茶杯类装置** ✅：B 站译文作「蓝色大型茶杯 / 薄荷大型茶杯 / 蓝色精致茶杯 / 薄荷精致茶杯」，官中为**大型蓝色茶杯、大型薄荷茶杯、精致蓝色茶杯、精致薄荷茶杯**
6. **橡皮鸭（Rubber Ducky）** ✅：B 站译文作「橡胶鸭」，按 terminology.md 官中改为**橡皮鸭**
7. **爆炸球（Bomb Ball）** ✅：terminology.md 标注「一代作炸弹球／二代官中作爆炸球」，本条属二代，采用**爆炸球**
8. **彩虹岛 / 彩虹原野** ✅：Rainbow Island 官中为彩虹岛，Rainbow Fields 官中为彩虹原野，二者不可混用
9. **灰暗迷宫** ⚠️：0.5.0 结尾官方预告下一次更新时，B 站译文作「灰暗迷宫」，官中为**灰色迷宫**，正文已改正
