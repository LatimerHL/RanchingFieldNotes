## v1.0.0：正式发布（2017-08-01）

> 官方定性：v1.0.0 标志着抢先体验开发的结束、转入正式发布。对 Monomi Park 的每个人来说，和大家一起把本作做成今天的样子是一段难以置信的旅程，非常感谢过去一年半里大家给予的支持。「但这并不代表你在致远牧星上冒险的终点！」游戏仍会持续获得内容更新。v1.0.0 本身是个小补丁，旨在收束现有游戏里的一些小尾巴，并为当前这一版冒险模式画上句号。

**冒险模式完结**：
- 冒险模式新增最后的霍布森日志节点和凯西（Casey）的星际邮件——读完两者是「完成」冒险模式的必要条件
- 玻璃荒漠尽头新增一小片新区域，霍布森日志就在那里
- 新增两个成就
- 完成冒险模式并观看制作人员名单的玩家，会有一个小惊喜（彩蛋）
- 「关于」界面新增重看制作人员名单的按钮（需先完成冒险模式才能使用）
- 调整「关于」页名单，尽可能展示所有为本作出过力的了不起的人们——「尽管这仍然意味着要略过那些没有直接参与、却让一切成为可能的人——哦，伊丽莎白，我实在是太爱你了。」

**牧场体验**：
- 调整园地逻辑：园地永远不会在收获途中自行消失，总会等作物成熟、留在地上后才消失
- 碧翠丝现在会出现在标题界面和她的房子里——「你好啊，碧翠丝！」
- 游戏加载开始时新增 logo 与启动画面
- 优化部分音乐与音效处理以减少内存占用；优化部分材质以减少内存占用；优化部分对象管理以小幅改善 CPU 占用
- 优化 Monomi Park 食品室的小吃布局以改善厨房使用；整体均衡各音乐曲目之间的音量
- 改善从树上/地上采摘水果/蔬菜的音效
- 调整牧场各处的部分几何体，防止物品卡住、减少弹出、避免其他奇怪交互
- 移除 HUD 上的抢先体验版本水印——「意外地让人神清气爽。」
- 调整史莱姆百科的文字间距
- 通往实验室的小路上加了几块木板——「因为一切伟大的科学，都始于通往更伟大科学的道路。」

**修复**：牧场周围有焦油怪时在小屋里睡觉，有时会卡住 / 某些水果蔬菜会穿过地板掉下去 / 马赛克史莱姆离玩家很远时仍会生成和管理闪光 / 某些语言下购买界面的布局问题 / 错误报告界面的布局问题 / 弹簧板会反复响应回声，即使它并不会把回声弹出去 / 采集器音效有时不播放 / 升级版实验室入口处的一处几何缝隙

**其他**：本作原声带现已在 Steam 开售（store.steampowered.com/app/671160）；本作试玩版也已在 Steam 上架（store.steampowered.com/app/433340）

> 梗备注：结尾制作人员名单调整那句「哦，伊丽莎白」为官方玩梗，保留语气翻译

## v1.0.1：导航更新（2017-08-07）

> 官方定性：期待已久的地图功能来了，外加一些小玩意儿，以及一堆修复和优化。

**地图（新增）**：
- 新增地图界面，让你对自己在致远牧星上的位置有个大致概念。地图区域需先激活各区域的地图数据节点才会解锁；地图会追踪你放置的传送器和采集器，并统计每个区域已收集的史莱姆钥匙与藏宝球总数

**新内容**：
- 为火焰、马赛克、旋风、藤蔓史莱姆新增史莱姆玩具
- 金姜（Gilded Ginger）现在每天在玻璃荒漠长一棵，但很难找。金姜是黄金史莱姆唯一会吃的蔬菜，喂食成功会奖励额外结晶；它没法在园地里种，但可以用来[已删除]——官方原文即如此（[REDACTED]）⚠️（见存疑 1）
- 实验室谷仓后面新增一个藏宝球，给新玩家造第一个传送器一个起步优势
- 喵喵史莱姆偷东西时新增音效
- 冒险模式新建存档时新增开场文字
- 霍布森金库新增返回传送器——「看了几场玩家在金库里意外身亡、痛失黄金结晶的直播，Nick 差点为他们哭出来。」
- 购买水槽时新增用水教程消息

**调整**：
- 采集器循环时间从 22 小时调至 12 小时——「请注意，我们省下的那 10 个小时没有浪费，被回收利用了。」
- 池塘现在像野外水源一样产出无限水
- 园地现在无限收获！要种新作物，需在园地菜单里选择重新种植
- 调整焚烧炉食槽，防止火焰史莱姆在食槽里消失——附注：空灰槽不会让火焰史莱姆消失，但也不会喂它们
- 牧场上的奇怪洋葱作物现在至少结 4 个，通常 6-8 个
- 朝黄金史莱姆射鸡仔儿现在能像其他资源一样把结晶震出来——附注：鸡仔儿们表示它们真的不喜欢这个改动
- 星际邮件弹窗在读完后会消失
- 离开牧场后，牧场专用教程在屏幕上停留的时间缩短
- 优化遮挡剔除；优化 GPU 上近乎零强度的方向光处理；优化部分内存使用

**修复**：部分玩家开启史莱姆大门和结晶门（plort puzzle door）的进度未被正确记录，影响他们收到某些凯西邮件 / 从斜角吸树上的水果会一直摇晃但弹不下来 / 法语翻译的若干问题 / 夜里睡觉时史莱姆没有正确变成大型史莱姆 / 夜里睡觉或被击晕后可能播放新音效 / 牧场刚加载时会有一些音效响起——「趣闻：这个怪癖在开发端一直存在，每次我们测试游戏都会先听到一会儿蟋蟀叫。现在我在现实中听到蟋蟀，就会想起我们的编辑器。」/ 未熟的相位柠檬会随树移相而穿过世界掉下去 / 旋风巨型史莱姆的钥匙会生成进地里 / 玻璃荒漠里一块漂浮的平台 / 不同宽高比下碧翠丝被拉伸 / Humble 安装程序没有完整替换旧安装的某些文件 / 某些几何体允许玩家靠太近看到墙内——「如果有玩家声称在墙里看到被奴役的侏儒在搭建我们的关卡，他们在撒谎。」（官方玩梗）/ Xbox 上暂停菜单会干扰其他游戏内界面

> 梗备注：「10 小时被回收利用」「Nick 差点哭出来」「蟋蟀想起编辑器」「被奴役的侏儒在撒谎」均为官方玩梗，保留语气翻译

## 存疑/待核 ⚠️

1. **金姜 [已删除]** ⚠️：1.0.1 官方原文即「it can be used to [REDACTED]」（官方自己打码的梗），无官中对应；本日志按字面保留为「[已删除]」并注明原文。游戏内实际用途：金姜在之后版本（1.2.x 起）用于开启金库/招财史莱姆诱饵等，但 1.0.1 原文未说明
2. **plort puzzle door（结晶门）** ✅：指古代遗迹庭院入口那扇以 6 种结晶开启的大门；一代仅此一扇以结晶开启的大门，可与 v1.2.0 竞速模式中的 plort gate 坐实为同一对象。正文统一称「结晶门」
3. **星际邮件 vs 星邮** ✅（2026-08-18 发明者定）：描述性文字统一用全称「星际邮件」；仅引用游戏内简中原文时保留「星邮」（本日志无直接引用游戏原文场景）
4. **霍布森·推格斯** ✅：Hobson Twillgers（双 l），官中全名「霍布森·推格斯」；正文以「霍布森」称呼
5. **「你这……禽兽！」成就** ✅：'You Monster' 成就官方简中名（焚烧小鸡成就），terminology/语料确认，1.0.1c 修复项用
