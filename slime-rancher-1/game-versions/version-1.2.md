## v1.2.0：莫奇的财富更新（2018-03-13）

> 官方定性：莫奇的财富更新来了！本次更新邀请牧场主探索迅捷峡谷、追逐全新的水银史莱姆、赢取豪华牧场升级，并挑战激动人心的快攻模式。

**迅捷峡谷**：
- 新区域，也是极其稀有的水银史莱姆的家园。除了这里归莫奇·迈尔斯所有以外，人们对峡谷所知甚少；为莫奇工作，证明自己是一流牧场主
- 解锁条件：与莫奇完成一次**新的**牧场交易所委托、解锁靛蓝采石场并购买幽暗山洞后，莫奇会邀请你前往她的庄园；旧委托不计入这次触发
- 峡谷工作由一系列牧场交易所委托组成，奖励新币和特殊升级。每上交 10 个水银结晶，莫奇都会「慷慨地」（应莫奇·迈尔斯要求特别强调）付你报酬；完成更大的委托可获得莫奇的特殊优待、鸡圈豪华升级，最终获得莫奇庄园的使用权
- 迅捷峡谷有两条资源收集赛道，其中一条更难
- 每条赛道都有特殊发电机，可将水银史莱姆从藏身处引出来。发电机运行时间有限，需要充能；穿过峡谷里的中继圈可延长可用时间
- 迈尔斯科技会自动替你收集水银结晶。莫奇保证自己没有从中抽成——你竟然会这么想，简直太过分了

**水银史莱姆**：
- 水银史莱姆快如闪电，以电力为食。它们平时靠高速移动慢慢积累静电，莫奇则用更直接的办法给它们喂能量
- 使用莫奇最先进的迈尔斯科技，让水银史莱姆带电并进食
- 收集结晶时要当心：触碰带电的水银史莱姆会受到伤害
- 水银结晶不能在结晶市场出售，只能存入莫奇庄园的交易终端

**电荷与充能设施**：
- **闪光弹**：喂给水银史莱姆，然后大赚新币
- **静电吸附器**：让一只水银史莱姆带电，并把电荷连锁传给附近的水银史莱姆——让它们为你干活
- **减速力场**：实验性科技，制造光子果冻穹顶，使穿过其中的水银史莱姆减速
- **雷霆弹**：超级充能的闪光弹，可一次命中一大群水银史莱姆
- **充能站**：随机提供减速力场、静电吸附器或雷霆弹，为真空储槽补充电荷
- **中继圈**：穿过后为发电机充能，延长剩余时间
- **能量增强站**：回满能量，让你继续奔跑、跳跃和收集结晶

**快攻模式**：
- 「五日快攻」被快攻模式取代
- 在限定时间内尽可能高效地经营牧场，赚取最多新币；被击晕会扣除 10% 新币
- 完成每日牧场交易所委托可获得额外时间和金姜
- 每收集任意一种结晶 25 颗，结算时便获得该类结晶的奖励倍率；每种结晶只能取得一次奖励，共 16 个倍率，玻璃荒漠史莱姆的结晶最值钱
- 地图各处新增巨型黄金史莱姆，可用金姜喂爆
- 可直接使用库存中的史莱姆科技装置，包括传送站、传送器和喷水炮台
- 为加快流程，模式中还预先喂饱了一部分巨型史莱姆、开启了一扇结晶门、解锁全部可用真空枪升级，并准备了一批史莱姆科技装置 ⚠️（见存疑 3）

**其他变化**：
- 「胡子岛（Moustache Island）」新增 3 个装置点——如果你正想问那是什么地方，别担心，它根本不存在 ⚠️（见存疑 1）
- 奥格登的别墅和莫奇庄园现在可与碧翠丝的主牧场分别着色
- 开启奥格登和莫奇的任务后会解锁特殊调色包；不过莫奇声明，换个角度看，现在其实只有一个调色包可用
- 赚取或花费新币时新增弹出文字
- 牧场教程只会在碧翠丝的牧场出现，不再出现在奥格登和莫奇的扩建区
- 帧率上限设为 120Hz，防止 GPU 过热；垂直同步模式不受该限制
- 新增关闭默认轻微鼠标平滑的选项
- 升级 Unity 引擎版本；翻新新币图标
- 改进配置文件数据的存储方式，不同电脑现在可以使用不同选项
- 改善手柄操作地图时的滚动
- 调整「五日快攻」成就，使其更适合快攻模式

**修复**：黄金史莱姆逃跑行为可能异常 / 藤蔓史莱姆的藤蔓与旋风史莱姆的旋风有时会把史莱姆或其他物品弹飞 / 干涸岩礁一处会卡住没有喷气背包的玩家 / 丰茂原野一处树后会卡住鸡——「那里大概是鸡群密谋的秘密基地，所以不用谢！」 / 真空枪旋转角度的轻微偏移 / 读档时结晶市场把所有价格都显示为上涨——「谢啦，莫奇。」 / 读档时绿洲音乐有时不正常播放 / 玩家在园地教程提示前种下作物会卡住教程 / 快攻模式会发送牧场主介绍邮件 / 黄金史莱姆、招财史莱姆与巨型史莱姆的食谱显示 / 身处辐射光环时传送，离开后仍可能持续受到辐射 / 仓储塔空储槽显示粉红史莱姆图标 / 从某些角度看古代遗迹的门会消失在现实中 / 碧翠丝睡觉时，史莱姆偶尔能隔着牧栏屏障进食 / 库卡粉碎机不播放粒子效果 / 霍布森日志的辉光会遮挡真空枪 / 牧场交易所箱子被打碎时会过于凶猛地喷出内容物 / 史莱姆生成错误地受鸡群密度影响——「谢了，鲍勃。」 / 受伤闪光不再闪烁——现在它又会闪了，因为疼痛不该被忽视 / 池塘里的火焰史莱姆有时没有正常消失 / 火焰史莱姆落水后没有熄灭 / 黄金史莱姆碰到黄金结晶也会产出结晶——「这一定得有个设定解释，来围过来听听《游戏平衡》的史诗故事……」 / 从箱子或交易所获得新币的计时问题，避免在不巧的时机退出游戏丢掉新币 / 幽暗山洞地板边缘的小缝隙 / 读档时教程会重新启动 / 采集器完成工作后没有彻底销毁自身 / 世界中某种常春藤不够浓密——「没错，你就知道这次更新会很棒。」 / 读档与存档错误界面的手柄导航 / 制造器界面缺少「需要」标签 / 靛蓝采石场中央洞穴被误判为牧场的一部分 / 低精度蜂蜜史莱姆模型的头冠错误 / 读档时最大能量先被限制为 100，再开始回充 / 世界中少量区域光照错误 / 「禁用手柄」选项无法正确保存 / 「omelettes」拼写错误——现在正确拼作「花式鸡蛋玉米卷」 / Linux 恢复默认屏幕分辨率的问题 / 少量水体渲染问题 / 其他各种小型优化

> 梗备注：「慷慨地」强调、莫奇抽成、鸡群秘密基地、「谢啦，莫奇」「谢了，鲍勃」、《游戏平衡》的史诗故事、常春藤厚度与「花式鸡蛋玉米卷」均为官方玩梗，按原意保留

## v1.2.1：小型大容量更新（2018-04-03）

> 官方定性：几百个回响还飘在角落里？几千个嘟嘟乐园装饰品还塞在幽暗山洞里？小型大容量更新来帮忙了！牧场存储迎来大升级，正好赶上一场春季大扫除。

**存储升级**：
- 仓储塔与传送站现在可以存放装饰品和回响
- 仓储塔和传送站的单储槽容量从 100 提高到 300
- 仓储塔每一面现在有 3 个储槽——总计 12 个储槽，每个可放 300 件物品；「自己算算看！」

**成就**：
- 解除 Steam 成就与游戏内成就之间的绑定，更好地支持多人共用一台电脑、分别使用不同 Steam 账户游玩
- 重置游戏内成就不再重置 Steam 成就
- 在 Steam 上新建游戏时，游戏内成就不再同步
- 如果获得成就时只解锁了其中一种记录（游戏内或 Steam），现在会弹出缺少的另一种成就通知
- 快攻模式中不再授予非快攻模式成就
- 调整仓储塔成就，不再要求把升级后的仓储塔完全填满

**其他变化**：
- 加薪了：每上交 10 个水银结晶，莫奇现在会支付 200 新币
- 为迅捷峡谷倒计时动画新增炫目效果
- 为快攻模式新增开场动画；结算动画也多了一小撮华丽效果——「老实说，远不止一小撮。」
- 世界中掉落的新币现在会更快被拾取并装进口袋
- 新增一套能「看穿时空」的存档机制，避免牧场主调整系统时间或在不同电脑访问牧场时引发混乱
- 打开地图后会立即完成地图教程——这样就完成了地图教程
- 更新部分俄文翻译

**修复**：切换语言后，真空储槽中物品名称不会随之翻译 / 「修好」牧场闹钟的贪睡按钮，碧翠丝不再能一觉睡过早上 6 点 / 玻璃荒漠一处会卡住玩家的危险位置 / 莫奇庄园在扩建屏障开启前有一处会卡住玩家 / 迅捷峡谷一处会卡住玩家 / 雷达图标移动时偶尔抖动——「至少这回不是卡住了！」 / 真空枪移动时抖动 / 有牧场主利用传送站与仓储塔的狡猾组合，把水银结晶偷运出迅捷峡谷 / 「喵喵太空计划」相关问题——喵喵史莱姆企图坐火箭上月球 ⚠️（见存疑 2） / 火焰史莱姆看到碧翠丝回到牧场时会兴奋地从灰槽里弹出去 / 焚烧炉会烧掉马赛克史莱姆的闪光——它们不再「以火攻火」 / 莫奇庄园图标未显示在传送器上 / 调整水银史莱姆音效，让它们听起来终于像水银史莱姆

> 梗备注：「看穿时空」存档机制、地图教程自指、闹钟「修好」、「至少不是卡住」、喵喵太空计划与「以火攻火」均为官方玩梗，按原意保留

## v1.2.2：骚动我们的Party！（2018-05-22）

> 官方更新名：Let's Get This Party Started!；fandom 中文 wiki 版本名「骚动我们的Party！」。本版本引入常驻的派对周末活动与派对巨型史莱姆。

**派对巨型史莱姆来了**：
- 每个周末，派对巨型史莱姆都会来到致远牧星，但得先找到它：搜索藏在地图某处的派对巨型史莱姆并把它喂爆，就能获得大量派对礼物，里面装着可用于牧场的节日装饰品
- 派对不会就此结束：整个周末还可在世界各地发现隐藏礼物。即使派对巨型史莱姆已经离开，派对也会……继续下去
- 派对巨型史莱姆会在当地时间的周五、周六、周日全天出现，并在之后每个周末带着新宝藏回归

**变化**：
- 新增官方中文翻译——「欢迎，朋友们！」
- 改进并优化游戏存档与动画对象
- 改善打碎箱子的视觉效果——「趣闻：这件事大概在我们的待办清单上躺了 100 年。」
- 新增 Discord Rich Presence（丰富状态），现在好友能看到你在致远牧星的位置和正在做的事

**修复**：部分快攻模式翻译在结算界面放不下 / 物品有时会卡进牧栏屏障 / 莫奇庄园部分位置会卡住玩家 / 被苔岛部分位置会卡住玩家 / 改善受伤指示效果 / 莫奇对话中的错字——莫奇要求官方说清楚：犯错的是他们，不是她 / 仓储塔存储界面的部分动画问题 / 手柄按钮图标切换到正确图标前会短暂显示一帧错误内容 / 装饰品朝向略微向下——官方已经叫它们抬起头来 / 睡到早晨期间仍可弹出部分界面 / 在迅捷峡谷奔跑时射击偶尔不准——莫奇再次声明，这一直都是你的错

> 梗备注：「派对仍会继续」「待办 100 年」、莫奇甩锅与装饰品「抬起头来」均为官方玩梗，按原意保留

## 存疑/待核 ⚠️

1. **Moustache Island（胡子岛）** ⚠️：实际是干涸岩礁外海可经传送器抵达的隐藏岛；更新日志声称「它根本不存在」是在故意装傻、隐藏彩蛋，不是事实说明。terminology 与游戏内词条均无正式译名；LatimerRowe 的 v1.2.0 翻译博客旧译「把手岛」，正文按 moustache 字面暂译「胡子岛」并保留英文
2. **Tabby Space Program（喵喵太空计划）** ⚠️：官方玩笑式项目名，无游戏内正式条目与官中译名；LatimerRowe 旧译「喵喵太空计划」，本日志沿用并注明原文
3. **plort gate（结晶门）** ✅：快攻模式预先开放的门；一代仅古代遗迹庭院入口这一扇大门以结晶开启，可与 v1.0.1 的 plort puzzle door 坐实为同一对象。正文统一称「结晶门」
4. **v1.2.2 中文版本名** ⚠️：fandom 中文 wiki 原样写作「骚动我们的Party！」，中英混排且不是游戏内官中；本日志按用户指定的「中文 wiki 拉版本名」规则照录，英文原名为 Let's Get This Party Started!
5. **Mochi's Extra Mile** ✅：LatimerRowe 旧译「莫奇的双倍金币」，游戏内官中与知识库口径为「莫奇的特殊优待」；正文采用官中
6. **Deluxe Coop** ✅：游戏内设施升级名为「豪华升级（Deluxe Upgrade）」；正文按语境写作「鸡圈豪华升级」，不沿用旧译「豪华鸡笼升级」
7. **Rush Mode** ✅（2026-09-27 修正）：官方简中为「快攻模式」（UI `m.gamemode_time_limit_v2.long`；成就作「快攻挑战者/快攻冠军/快攻大师」）；繁中手游作「衝刺模式」；此前记录的「竞速模式」系误记，已全库更正
8. **Nimble Valley** ✅：旧译在「迅捷峡谷 / 迅捷山谷」间混用；terminology 官中为「迅捷峡谷」，正文统一采用官中
9. **v1.2.2 日期差一天**：英文 fandom 记为 2018-05-22，LatimerRowe 中文翻译博客记为 2018-05-23，属于发布时间与时区口径差异；本日志按英文 Game Versions 页日期记 2018-05-22
