## v0.4.0：史莱姆科技更新（2016-11-16）

> 官方定性：史莱姆科技是有史以来最大的一次更新——全新功能，可制造装置并放置到世界各处；官方预告未来会继续扩展史莱姆科技，还有更多史莱姆与可探索区域。

**史莱姆科技（Slime Science）**——本次更新内容多，官方把日志按新功能拆块介绍：

- **如何解锁**：购买新牧场扩张「实验室」后开放；购买后开始简短教程，讲解史莱姆科技基础；史莱姆百科新增「史莱姆科技」标签页可看更多信息
- **实验室（The Lab）**：新牧场扩张，含一间旧谷仓——霍布森曾把它改造成自制史莱姆科技实验室
- **精炼炉（Refinery）**：用先进技术把结晶等资源分解到分子层面，用于制造各种史莱姆科技装置
- **建造者商店（Builder's Shop）**：出售设计图；制造各种装置是解锁新设计图的最佳途径
- **设计图（Blueprints）**：在制造器处按图制造装置；拥有某装置的设计图后，只要有资源且不超过建造上限，想造几次造几次
- **制造器（Fabricator）**：用精炼炉中储存的资源，按设计图制造装置
- **藏宝球（Treasure Pods）**：现在散落致远牧星各处（有些藏在超级秘密的藏点里！），内含独占设计图，但只能用藏宝球破解器开启——破解器可在真空枪升级商店购买
- **装置模式（Gadget Mode）**：真空枪新模式，解锁史莱姆科技后可切换；开启后所有可能的装置建造点可见，可安装拥有的装置；但装置模式下不能吸取或射击

超过 45 种装置可解锁（未来更新还会增加），全部归入 5 类：

- **采集器（Extractors）**：建造其他类型装置的基础，含钻机、泵机、蜂房。放置到建造点后开始工作，随时间从环境采集资源；装满可清空；最好的采集器可重复多个循环才最终损坏
- **工具（Utilities）**：提供实用功能的装置，辅助管理牧场与探索
- **传送科技（Warp Tech）**：驾驭瞬时移动之力，含传送器（创造捷径）与运输物品的装置
- **装饰（Decorations）**：用美观物件或环境自然造物的复刻来装饰世界
- **珍玩（Curios）**：有功能但未必有用的装置，含玩具、游戏等小机巧玩意，"配上同样大的想象力可以玩得很开心"

**改动**：
- 干涸岩礁与被苔岛新增可探索区域；被苔岛新区域（同岩礁/采石场先例）对将来某次更新很重要
- 显示选项新增垂直同步开关（防画面撕裂，但可能影响帧率）
- 干涸岩礁环礁岛新增一只巨型史莱姆
- 各区域大量小改进与美化（"若你有意优化，也许能从中得到启发"）
- 通知商店新商品的星际邮件移除，改为百科式弹出通知；星际邮件只留给最重要的信件，"也许偶尔会有银河系王子来讨新币"
- 牧场扩张屏障远处观感更低调、不扰视线
- 所有购买界面文字调整，包括拆毁存有物品的设施（如仓储塔）前新增警告
- 购买界面购买后不再自动关闭——配合牧场科技可立即连买设施升级
- 移除关闭教程的选项（防止玩家错过史莱姆科技教程等未来教程）

**修复**：牧场交易所未把已解锁的被苔岛/靛蓝采石场正确物品计入（"这bug我们大概修了五次了，我已在想下次怎么措辞"）/ 索拉·韦斯特星际邮件中一段过时且令人困惑的内容 / 焚烧炉相关内存泄漏（"它真的在烧你的内存。疯狂。"）/ 某些视角下世界大块弹现，尤其透过树看时（"树藏着许多秘密"）/ 特定设置下从某些视角史莱姆之海偶发隐形 / 离开游戏后主菜单出现教程弹窗（"我们同意学无止境，但它很烦人"）

- 新增 3 种风格皮肤：小可爱、花花公子、皇家

- 收音机新增一首夜间音乐（"相当浪漫"）
- 改用新文字渲染/排版库，特定情况下文字清晰度与换行、尺寸改进
- 水滴史莱姆更少蹲在池塘角落（"告诉它们：愿意与他人合群时，世界更明亮"）

- 抱住大型史莱姆时玩家被推挤的处理改进（尤其快速转身面向墙时）

- 结晶收集器新增吸取音效
- 手柄拔出时游戏暂停
- 巨型史莱姆撑爆所需食物数量略减

**修复**：方方莓卡在树顶 / 海洋球成就误发 / 沿陡坡边缘移动的卡位问题（防某些卡住动不了几秒的情况——"我们没有给游戏里所有悬崖侧壁抹油，根本没这回事"）/ 自动喂食器升级回牧场时处理不当，导致牧栏堆积大量食物（该修复整体改善自动喂食器体验）/ 紧急返回偶发把玩家送到过高或过低处（"真的变成了另一种紧急情况"）/ 部分俄语翻译改进 / 精炼链接投料口调得更易接收 / 垂直同步设置偶发未正确初始化

**其他**：最低内存要求从 2GB 改为 4GB——随功能与区域增多内存占用上升，也反映新版本 Windows 本身占用较多系统内存；"简而言之，如果你一直能跑本作，什么都不用变。"
