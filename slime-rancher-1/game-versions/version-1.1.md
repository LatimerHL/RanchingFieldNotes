## v1.1.0：奥格登的荒野更新（2017-10-17）

> 官方更新名：Ogden's Wild Update（奥格登的荒野更新）。官方定性：一个危险的新区域可供探索、奥格登·奥提兹（Ogden Ortiz）的任务、早已灭绝的剑齿史莱姆的狂暴后代，还有更多！WeGame 视频版本名：奥格登的荒野更新。

**荒蛮群岛（The Wilds）**：
- 新区域，一群狂暴剑齿大型史莱姆的家园。收到奥格登·奥提兹的邀请后才能前往他在荒蛮群岛边缘的隐居地；奥格登会雇你去荒蛮群岛采集美味的库卡多巴果并给予奖励
- 触发条件：与奥格登成功完成至少一次牧场交易所、解锁被苔岛、解锁丰茂原野后，奥格登会发星际邮件邀请你去他的别墅
- 为奥格登工作通过他别墅里改造过的牧场交易所进行：他会要你交三批数量递增的库卡多巴果，每批都有奖励，此外每交三个库卡多巴果还有小额奖励
- 与普通牧场交易所不同，别墅里的奥格登任务没有时间限制
- 奖励包括：奇迹混合（Miracle Mix）、园地豪华升级，最后是别墅钥匙本身！
- 库卡多巴果只在荒蛮群岛随机位置生长，会随时间重新长出——如果荒蛮群岛被采光了，得等几天才能长全
- 部分库卡多巴果藏在剑齿史莱姆捏的古怪泥球里；泥球必须带去荒蛮群岛中的库卡粉碎机（kookacracker）才能取出里面的果实
- 通往荒蛮群岛的传送网络故障不断、极不可靠！你会被传送到四个位置之一，且无法立即离开，只有到达三个出口传送器之一才能脱身。另外荒蛮群岛偏离地图网格太远，你的地图无法使用——「这看起来像是为了增加难度而硬凑的设定，但并不是，这完全是因为剧情设定（LORE）。」（官方玩梗）

**新牧场交易所**：
- 牧场交易所视觉翻新、奖励调整、时机重新校准
- 24 小时计时器现在从接受报价后才开始计时
- 所有牧场主的介绍性报价之后，每日报价变为在两位牧场主之间二选一
- 所有报价重新平衡，并新增新币奖励
- 界面改为更像与每位牧场主直接交流的形式——「奇怪的是，其中一位仍然依赖打字消息……」（指鲍勃 BOb，官方玩梗）

**休闲模式（Casual Mode）**：
- 新增游戏模式，给想用《史莱姆牧场》真正放松的玩家。与冒险模式完全独立，区别是完全没有焦油怪、狂暴史莱姆攻击性降低。休闲模式下大型史莱姆不能吃第二个结晶，狂暴史莱姆不会表演它们招牌的狂暴史莱姆跺臀舞
- 注意：由于没有焦油怪，部分成就在休闲模式下可能无法获得

**其他变化**：
- 结晶市场视觉翻新以容纳剑齿结晶，也为将来的其他结晶做准备；存入结晶的音效现在带感得多
- 荒蛮群岛中可找到剑齿大型史莱姆——迄今从未发现过原生剑齿史莱姆
- 从树上吸水果的速度提升
- 可从奥格登处获得辣豆腐（Spicy Tofu）：万能食物，任何史莱姆都能吃且不影响饥饿度，可反复喂食
- 荒蛮群岛中发现一堆新的装饰装置
- 喂食过至少一次的巨型史莱姆会出现在地图上
- 园地中种植的相位柠檬树现在像普通果树一样，不需要再把柠檬移相到现实——「为了这个生活质量改动，我们改变了空间和时间运作的方式。没什么大不了的。」（官方玩梗）
- 调整真空枪发射与市场存入结晶的部分特效
- 长时间离开牧场后回到牧场，园地内容的处理更真实
- 火焰史莱姆「裤子里没了蚂蚁」（lost the ants in their pants），不再朝玩具蹦跳——那会让它们送命。「让这成为你们所有人的教训。」（官方玩梗）
- 删除存档文件现在需要长按，降低误删概率
- 触发自动保存时，屏幕右上方会出现一个小真空旋风涡——「看到它时快速按下并行动不会把你传送到烟雾史莱姆的老巢。」（官方玩梗，烟雾史莱姆并不存在）
- 新增过扫描（overscan）调整选项；分辨率选项新增刷新率选项（若显示器支持）；新增手柄盲区选项
- 更新底层 Unity 游戏引擎版本——可能带来一些有用的优化与修复，但也可能对世界物理造成轻微/微妙变化，官方请求玩家反馈
- 其他各类物理与渲染优化
- 史莱姆玩具店新增剑龙玩偶（stego buddy），剑齿史莱姆喜欢
- 7Z奖励俱乐部实验室升级新增大量细节
- 招财史莱姆的「火箭燃料」被换成额外新币：现在跳得没那么高，但奖励的新币多得多
- 狂暴史莱姆有时会停下来瞪着你而不是扑上来攻击，免得它们像无情的暴徒
- 藤蔓史莱姆的藤蔓抓取半径减少 33%
- 完成冒险模式后，升级商店新增一把史莱姆钥匙——给在抢先体验期间丢过钥匙、或实在找不到最后一把钥匙的人。注意：如果你把每把钥匙都用在了每扇门上还买了这把额外的钥匙，你会永远多出一把钥匙

**修复**：焦油怪偶尔会播放错误的非焦油怪音效——「虽然很萌，但得改。」/ 新开游戏时焦油怪音乐或绿洲音乐有时会响起 / 带音乐盒的牧栏被拆除后，里面的史莱姆仍保持被安抚状态——「我是说，有些歌你就是挥之不去……」/ 牧场门开关音效不播放 / 玩家掉进史莱姆之海/沙海没有音效 / 草和花有时继承背后物体的环境光遮蔽的暗色 / 离开小屋时反复按 Esc 会重播离开小屋的淡入序列 / 被捕的荒漠巨型史莱姆撑爆前需要的食物比野生同类少 / 鸡会卡在丰茂原野的坡道下 / 狂暴史莱姆有时看起来卡在玩家面前然后才咬人 / 古代遗迹中的箱子不会掉出一整套物品 / 水滴史莱姆和橡皮鸭会因码头的一个 7Z 升级而被困住 / 史莱姆有时会因进食、叼食物等交互把自己弹出狭小空间 / 牧场主的介绍性牧场交易所请求有时会被后来的请求覆盖——「当然，这跟鲍勃特别难分辨。」/ 回到牧场时，本应被史莱姆吃掉的食物有时残留在世界里 / 某些分辨率下史莱姆百科部分图标显示异常 / 夜间光照设置略微不准 / 有时能把小资源射进/射穿地面 / 远处观看时古代遗迹的树显示异常 / 金姜被黄金史莱姆吃掉时「帽子戏法」成就未授予 / 炸弹史莱姆的爆炸会把回声炸飞——但看过玩家造的绚丽烟火后，官方承诺未来会以更正式的形式重现这个发现 / 已在史莱姆之海中时重新读档，有时不会把玩家送回牧场 / 荒漠史莱姆玩具不在第二档 7Z 史莱姆玩具奖励列表中 / 部分水晶史莱姆的水晶冠看起来像岩石冠 / 公鸡有时早上不打鸣——「解决办法是给那只公鸡配一只公鸡，确保原来那只按时醒来。」（官方玩梗）

## v1.1.1：平衡与改进（2017-11-28）

> 官方定性：一个平衡与改进补丁，同时引入新的存档备份系统。

**存档系统改进**：
- 游戏现在保留多份历史存档，防止系统崩溃或断电导致数据损坏。若无法加载最近的自动存档，会回退到能找到的最近一份。为此自动存档频率降至每 5 分钟一次

**变化**：
- 新增瑞典语翻译——「欢迎，瑞典朋友们！」
- 牧场交易所现在显示当前报价剩余时间的倒计时
- 荒蛮群岛的传送器现在通向奥格登的别墅，而不是直接到碧翠丝的牧场
- 牧栏自动喂食器在低/中档下的频率降低，分别改为每 9 小时和每 6 小时喂一次
- 新增教程「星标」，指引你前往通往奥格登别墅的传送器
- 焦油怪的史莱姆百科词条现在在休闲模式下立即解锁——「但别担心，在休闲模式里它们也就仅此而已了。」
- 若干着色器的次要改进——「没错，就是次要改进。」（官方玩梗）
- 优化世界中大量粒子的实例化方式以改善内存占用
- 腐烂的库卡多巴果现在看起来明显更烂——「但无论如何，它们都很臭。」
- 火焰风暴效果在传送进出荒漠时现在启停更快
- 「园地豪华版（Garden Deluxe）」更名为「豪华升级（Deluxe Upgrade）」
- 加载界面新增一条关于存档图标的提示

**修复**：琥珀色史莱姆灯笼的辉光能透过墙壁看到 / 荒蛮群岛瀑布附近的一些大型史莱姆会悬在半空——「趣闻：因为它们以为自己还在水里，在'游泳'。看吧，只要你想，什么都能做到！」/ 某些特效有时会让水消失 / 某些系统上装置模式特效上下颠倒 / 某些画质设置下，咬人的焦油怪体内看起来还有一只更小的焦油怪——「瘆人。」/ 炸弹史莱姆有时变得昏昏欲睡，停止大多数活动（包括爆炸）/ 焦油怪和火焰史莱姆被弹射出池塘时弹得太猛 / 「帽子戏法」成就可能被错误地扣住不发 / （Xbox 专属）手柄断开时游戏内手柄图标变成键盘/鼠标提示 / 库卡多巴果在读取存档时有时没有正确挂在植株上 / 荒漠中某个传送器的图标在其实际可用之前就出现在地图上

## v1.1.2：嘟嘟乐园2017（2017-12-19）

> 官方更新名：Wiggly Wonderland（2017）。fandom 中文 wiki 版本名：嘟嘟乐园2017；LatimerRowe 活动介绍译名为「欢迎来到黏黏仙境！」（「黏黏仙境」为翻译备注，本日志正文按知识库既有口径用「嘟嘟乐园」）。本版本为限时节日活动版本，无补丁。

**限时活动：嘟嘟乐园**：
- 限时活动，主题是每日「装饰品」：为牧场准备的节日新装饰。**从明天（12 月 20 日）起**（当地时间），致远牧星每个箱子都能找到藏起来的装饰品 :) 
- 12 月 20 日至 31 日期间，箱子每天包含一个**不同的史莱姆主题装饰品**；新装饰品在当地时间午夜刷新。趁它们消失前赶紧收集！
- 官方会在 Twitter 上每天公布当天装饰品
- 每个箱子都有机会开出**三种稀有装饰品之一**——记得留一个空的储槽备用！！

**节日抽奖**：
- 官方同步举办节日赠礼活动：记得 Fangamer 那些好东西吗？官方送出整套周边！
- 用装饰品和回声装点牧场、把装饰挂上树、晒出你的节日布置，在 Twitter 上用 #WigglyWonderland 发图，有机会赢 Fangamer 的《史莱姆牧场》周边组合；获奖者 1 月 3 日选出
- 活动期间每天都能参加；所有 Twitter 投稿还会参与抽奖，每天一名幸运儿赢取一份《史莱姆牧场》+ 原声带礼物副本

**12 天隐藏节日宝藏**（每日史莱姆主题装饰品）：
- 12月20日 - 粉红 / 12月21日 - 荧光 / 12月22日 - 喵喵 / 12月23日 - 炸弹 / 12月24日 - 辐射 / 12月25日 - 蜂蜜 / 12月26日 - 量子 / 12月27日 - 猎猫 / 12月28日 - 水滴 / 12月29日 - 旋风 / 12月30日 - 藤蔓 / 12月31日 - 马赛克
- **1月1日 - 最后机会！**：每个箱子都会开出活动期间登场的 15 种史莱姆装饰品之一（随机）⚠️（见存疑 4）

> 附注（官方提醒）：手动调整系统时钟进行「时间旅行」可能会造成《史莱姆牧场》存档备份系统和 Steam 云存档出问题。
