# 版本 0.2.x 更新日志（一代）

> 来源：fandom「Game Versions/Version 0.2.x」（原官方公告 forums.monomipark.com，论坛已关闭，此为 fandom 存档）；2026-08-18 拉取并本地化
> 术语：以 terminology.md 官中为准；存疑处已标注 ⚠️
> 备注：一代 0.2.0/0.2.1 无独立 fandom 页面（更早日志见 fandom 用户博客「Early Development」）；0.2.x 期间游戏处于 Steam 抢先体验阶段

## 版本 0.2.2（2015-12-30）

**改动**：
- 整理园地重植流程，并新增相关教程
- 提高牧场扩张的价格
- 为巨型史莱姆添加食性指示器
- 史莱姆与结晶撞到表面时不再那么弹跳

**修复**：
- 修复 Windows 上窗口失焦（Alt+Tab/多显示器）时游戏锁死的问题
- 修复园地有时不生长作物的问题
- 修复史莱姆从牧场部分区域（尤其扩张区）消失的问题
- 修复升级会带到新游戏的问题
- 修复重载游戏后星际邮件丢失的问题
- 修复部分画质设置在重载后未重新生效的问题
- 修复重载游戏时偶尔多生成食物的问题
- 修复稻草焦油怪效果远超预期的问题
- 修复奥格登的交易所奖励有时会送出史莱姆的问题
- 修复初始教程有时不立即开始的问题
- 修复部分鸡未正确转化类型的问题
- 修复多处几何问题（穿墙等）
- 修复多处拼写错误

## 版本 0.2.3（2016-01-12）

**改动**：
- 主菜单显示版本号
- 新增大型史莱姆教程，以及提示"初始教程已全部完成"的通用教程
- 手柄与鼠标均新增视角反转（Y 轴）选项
- 淡水中的焦油怪现在会像被水击中一样反应
- 改进各种购买界面与史莱姆百科界面的选中项指示
- 移动存档位置（原在 `SlimeRancher\SlimeRancher Prototype` 目录，现为 `Monomi Park\Slime Rancher`）；游戏会自动复制旧存档，无需手动操作
- 园地新增指示器，显示当前作物还能维持多久需要重植
- 调整多项牧场设施、升级与扩张的价格
- 减少牧场交易所单次委托要求的史莱姆数量
- 新增一些屏障，限制对牧场扩张区域的访问
- 新增（可能临时的）「紧急返回」选项：卡住时可自晕并返回牧场（带有通常的晕厥惩罚）

**修复**：
- 修复用手柄射击持有的巨型史莱姆/板条箱失败的问题（需在手柄设置中重新绑定发射键生效）
- 修复空气推进升级效果强于预期的问题
- 修复水下吸取未收集到水的问题
- 修复过于拥挤的幽暗山洞/丰茂原野仍会丢史莱姆的问题
- 修复扩张门解锁后仍会触发的问题（现在会正确弹出对应扩张的史莱姆百科页）
- 修复世界中偶尔出现迷你蔬果的问题
- 修复大型岩石喵喵史莱姆有时多出尖刺的问题
- 修复结晶价格停止更新的问题
- 修复母石楠鸡不刷新的问题
- 修复在幽暗山洞内退出游戏导致主菜单场景光照异常的问题

### 版本 0.2.3b（2016-01-13）

**改动**：
- 调整小屋背景图
- 延长探索教程在屏幕上的停留时间

**修复**：
- 修复营养土导致园地蔬果产量不足的问题
- 修复体力/能量/弹药升级有时会带进新游戏的问题
- 修复浇水相关偶发卡顿的问题
- 修复池塘过易重新灌满的问题

## 版本 0.2.4（2016-01-20）

> 0.2.4b 已上线！主要是修复补丁。本次更新**可保留存档**。

**改动**：
- 调整炸弹史莱姆的爆炸时机，显著降低同区域多只同时爆炸的概率
- 新增完全禁用游戏手柄/摇杆输入的选项（可防止其他方案无法解决的镜头旋转问题）
- 提高鼠标灵敏度滑杆的范围
- 新增「安全模式」（低画质）：强制以最低画质启动——在 Steam 库中右键游戏条目选择"安全模式"
- 略微调整结晶市场的位置
- 水滴结晶撞击硬表面碎裂时新增水花效果
- 史莱姆大门上的钥匙图标更清晰
- 世界中新增一些"施工中"标牌

**修复**：
- 修复幽暗山洞内史莱姆与鸡消失的问题
- 修复远处看牧场上的牧栏/园地漂浮在空中的问题
- 修复园地作物倒计时文字的格式问题
- 修复仓储塔重载游戏后有时丢失内容的问题
- 修复游戏名允许特殊字符导致后续存档失败的问题
- 修复用水射击水滴结晶与水滴史莱姆会使其消失的问题
- 修复牧场交易所委托有时会带进新游戏的问题
- 修复跳跃时偶尔播放脚步声的问题
- 修复部分音效忽略"音效"音量设置的问题
- 修复游戏时间卡在快进模式的问题
- 修复紧急返回确认框在 Esc 下无法正确关闭的问题
- 修复低画质下荧光史莱姆没有翅膀的问题
- 修复大型炸弹岩石史莱姆会吃水果变成焦油怪的问题
- 修复史莱姆百科描述中的一些拼写错误
- 减少首次弹出史莱姆百科时的卡顿
- 修复史莱姆百科有时未正确解锁初始真空枪/牧场页面的问题
- 修复鼠标或手柄控制视角需先按任意键才生效的问题
- 修复喵喵史莱姆及大型喵喵史莱姆盯着食物发呆的问题
- 修复重载游戏时园地作物偶尔提前成熟的问题
- 修复物体可能卡进结晶收集器收集箱的问题

## 版本 0.2.5（2016-02-24）

> 正忙于下一个内容更新（v0.3.0 靛蓝采石场）之际发布的平衡/修复补丁；可使用现有存档。
> 关于抢先体验与补丁结构的说明见官方 FAQ。

**改动与平衡**：
- 改进结晶出售的经济反应
- 更新稻草焦油怪模型——弹弹的！
- 改进真空枪同时按住射击与吸取时的操控（现在稳定执行最后选择的模式）
- 改进气网对荧光史莱姆的容纳能力
- 改进存档处理，最大限度降低存档损坏概率
- GIF 渲染快捷键默认改为 G（此前玩过的玩家仍保持单引号键）
- 版本号水印略微缩小
- 新增键鼠/手柄控制的恢复默认按钮
- 从淡水泉收集水更轻松
- 改进史莱姆之海、淡水与真空枪喷水的水体视觉效果
- 调整逻辑，让各区域音乐的变奏更常播放
- Humble 平台下载的 Windows 版改为安装包形式

**修复**：
- 修复炸弹史莱姆爆炸预热音效忽略音量设置的问题
- 修复史莱姆百科部分拼写错误
- 修复真空枪喷水相关的内存泄漏
- 修复「海洋球」与「666」成就过早发放的问题
- 修复荧光史莱姆所在遮光罩移除后未察觉的问题
- 修复经济系统在新游戏中有时未正确重置的问题
- 修复自动喂食器与结晶收集器重载游戏后时机错误的问题
- 修复玩家手持大型史莱姆时仍可从仓储塔/结晶收集器取物的问题
- 修复物体可从真空枪穿过地板/墙壁发射的问题
- 修复普通鸡仔儿无法存入仓储塔/喂食器的问题
- 修复碧翠丝用手柄购买时会跳起的问题
- 修复真空枪动画相关 bug
- 修复玩家可反复按「睡到天亮」进入持续快进模式的问题
- 修复首个史莱姆百科弹窗显示明显延迟的问题
- 修复多个史莱姆同时吃同一食物的问题
- 修复星际邮件内容初始未滚动到正确位置的问题
- 修正「飞速交易」成就的条件描述
- 修复「多元化」成就提前达成的问题

- 修复部分史莱姆在水下隐形的问题
