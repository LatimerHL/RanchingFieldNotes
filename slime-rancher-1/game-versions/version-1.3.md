## v1.3.0：自动化更新（2018-07-17）

> 官方定性：无人机现已到来！这些快乐的小帮手机器人可以接受编程，替牧场主完成牧场里的多种工作。

**无人机**：
- 无人机是一种新装置，可减少牧场主维持牧场运转所需的部分工作；它们能把食物送进牧栏、把结晶送到市场，或把多余作物存入仓储塔
- 无人机设计图现已在实验室出售；购买设计图后即可在制造器中制造无人机
- 使用 3 项简单指令编程无人机：目标、起点和终点
- 无人机可把物品送至传送站、小市场、仓储塔、自动喂食器等设施；可用终点会根据目标动态变化
- 无人机只能在单个牧场扩建区内工作，每个扩建区最多放置 2 座无人机站
- 无人机比看上去更聪明：它们不会搬空鸡圈，也会尽量避免过度喂食史莱姆
- 无人机站以水力驱动，需定期浇水才能保持运转；无人机大约能工作一天，缺水后花瓣会闭合，无人机也会休眠，直到再次浇水
- 无人机完成任务后会回站休息，等到需要再次工作时醒来

**新增语言**：
- 新增日语翻译——「こんにちは，新朋友们！」
- 新增巴西葡萄牙语翻译——「Oi, tudo bem?」

**其他变化**：
- 优化长时间未访问区域的重新载入体验：现在更像「欢迎回来！」，少了点「你为什么离开我？！」
- PC 使用 PS4 手柄时现在会显示 PS4 按键提示
- 调整音效音量与平衡
- 调整部分字体，使混排位置中的拉丁字符与中日文字形更加协调

**修复**：古代遗迹的相位柠檬树被浇水后会过度兴奋、反复切换相位 / 玩家昏倒后码头有时会生成一团水——「可那团水到底是谁？！」 / 部分史莱姆、尤其猎猫大型史莱姆即使身处极端环境也一直快乐平静，不会焦躁 / PC 上的 PS4 手柄无法打开游戏菜单 / 冲上码头的物品有时会不自然地直立——「我们修了，因为看起来实在太吓人」 / 水滴史莱姆与火焰史莱姆有时没有正确察觉自己不在适宜表面上

> 梗备注：「你为什么离开我」、水团「是谁」与码头物品诡异直立均为官方玩梗，按原意保留

## v1.3.1：优化更新（2018-10-23）

> 官方定性：本版本大幅改造多项底层系统，目标是显著提升性能；由于改动范围很大，仍可能出现测试中未发现的问题。

**游戏优化**：
- 升级游戏引擎，多数玩家应能获得性能改善
- 引擎升级至 Unity 2018，并重新组织全部游戏数据，优化数据存储与部分游戏状态的管理方式——官方称其中施展了「许多技术魔法」
- 大多数 PC 玩家以及全部 Xbox、PS4 玩家应能看到性能与整体帧率提升
- 不再支持 DirectX 9

**无人机改进**：
- 无人机现在可以把结晶送往精炼炉与精炼链接——为了科学！
- 将起点选项「外部区域」更新为「自由放牧」；选择后，无人机会收集扩建区内未被存入仓储塔、结晶收集器等设施的目标物品
- 更新编程界面：身处其他牧场扩建区时，无人机仍可通过小市场把结晶送往结晶市场；终点会按当前位置动态显示为「结晶市场」或「小市场」
- 更新焚烧炉编程逻辑：无人机只会运送食物，直到灰槽装满，不再无限销毁物品。如果你因为真的讨厌胡萝卜而想烧掉两千根，那就只能亲自动手——可它们只是胡萝卜啊
- 无人机现在可直接把仓储塔里的食物送进牧栏

**新增及更新语言**：
- 新增韩语翻译
- 全面翻新法语翻译
- 更新中文翻译

**其他变化**：更新派对巨型史莱姆的出现排期

**修复**：长时间未访问的区域中，水果与蔬菜几乎总是不成熟 / 奥格登的别墅部分物品会卡进地下 / 重新进入有无人机的区域时残留飞行轨迹 / 牧场主没看着时，无人机会从园地拿走胡萝卜而不是怪洋葱 / 某些其他种类的史莱姆会被计入「杂食动物」成就 / 某些分辨率下手柄按键绑定按钮不可见 / 灰槽在保存并重新载入后不能正确记住装满程度 / 部分翻译文字溢出界面 / 手柄选项的「重置为默认设置」会让 Y 轴反转选项进入不一致状态，使部分玩家分不清上下 / 结晶在保存并重新载入后不知道自己「该留下还是该离开」 / 狂暴史莱姆追逐玩家时跳进水里偶尔会冷静下来——这需要精细平衡它们的「又饿又气（Hangry）」参数；「游戏开发真有趣」⚠️（见存疑 2） / 黄金史莱姆会留下颜色错误、毫不华丽的黏液痕迹

> 梗备注：技术魔法、为了科学、焚烧两千根胡萝卜、分不清上下、结晶「该留下还是该离开」与「游戏开发真有趣」均为官方玩梗，按原意保留

## v1.3.2：免费银河套装DLC&嘟嘟乐园2018（2018-12-04）

**免费银河包 DLC**：
- Steam 独占的银河包现已推出，包含银河风格皮肤、哔哔机器人史莱姆玩具与红宝石调色包
- 银河风格皮肤可把史莱姆打扮成拯救星球的星际英雄，忠实的哔哔机器人会与它们同行
- 红宝石调色包可为牧场小屋、真空枪与牧场科技换上闪亮的新配色
- 「哔哔机器人最适合拿来戳一戳」

**嘟嘟乐园 2018**：
- 本版本为即将到来的节日活动做准备；完整活动公告会在更接近活动日期时另行发布
- 官方请求牧场主在正式揭晓前保守提前发现的惊喜——「谁也不想在圣诞袜里发现一篇焦油怪博客，对吧？」

**每日消息（仅 PC）**：
- 主菜单新增弹出消息，用于通知游戏更新、重大新闻及商品目录里的新毛绒玩具等内容 ⚠️（见存疑 3）
- 官方表示，这项功能是为了让牧场主及时掌握新消息——令人惊讶的是，显然并非每个人都使用 Twitter

**其他变化**：
- 「赞美水滴史莱姆！」池塘获得外观翻新
- 金姜现在每天会出现在 2 个位置；仔细聆听时也更容易定位
- 制作人员名单变长了一点，因为团队也壮大了一点
- 派对巨型史莱姆等特殊活动史莱姆在被发现前会隐藏起来，也不再是完成「高手范儿」成就的必要条件
- 调整水果与蔬菜的生长，确保进入某个秘密区域时总有成熟作物

**修复**：实验室和码头的碰撞体会让无人机在导航与交互时表演体操 / 商店偶尔没有把购买的史莱姆钥匙加入库存 / 非 Steam 手柄的部分输入问题 / 无人机看起来像在缩小物品，而不是把它们吸起来 / 稻草焦油怪有时不够吓人——现在又恢复成「史莱姆承受不了的吓人程度（2 spooky 4 slimes）」⚠️（见存疑 4） / 套装中的史莱姆玩具没有正确降低身穿对应风格皮肤的史莱姆的焦躁程度 / 玩家站着不动时焦油怪会停止啃咬——对付焦油怪的最佳方式是用水喷它们，或者快跑 / 地图显示的史莱姆钥匙数量不包含已经发现的钥匙 / 新币界面可能卡在屏幕上 / 少量本地化修复与改进

> 梗备注：焦油怪博客、Twitter、自我赞美水滴史莱姆、无人机体操、「2 spooky 4 slimes」与焦油怪追击警告均为官方玩梗，按原意保留
