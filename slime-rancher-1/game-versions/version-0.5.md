## v0.5.0：古代遗迹更新（2017-03-06）

> 官方定性：下一个大型内容更新——新可探索区域、新史莱姆、新资源，还有更多！
>
> 更新前提醒：若曾自定义过手柄/键盘/鼠标按键绑定，本次更新会将其重置为默认（需到选项菜单改回）；为避免玩家卡进新增的几何体，玩家在世界中的位置会被重置回牧场。

**古代遗迹（The Ancient Ruins）**——新区域，位于被苔岛与靛蓝采石场之间，包含新史莱姆、新资源与其他待发现的秘密；也是将来更新中进入玻璃荒漠的关键。官方特别提醒：遗迹与其他区域很不一样，牧场主在其曲折通道里很容易迷路——「旅途平安！」

- **量子史莱姆（Quantum Slime）**：古代遗迹原生史莱姆，能放出自身其他可能现实的投影，受惊扰时会与其中一个现实合并。官方提醒牧场主在牧场上要盯紧它们——而且要确定盯的真是那只量子史莱姆本体！
- **相位柠檬树（Phase Lemon trees）**：古代遗迹的另一奇异产物——一棵在多重现实中回响的果树，任一时刻只在一半现实里存在。量子史莱姆爱吃它的果实，但想把这些谜之柠檬收进我们的现实，需要某种「结合剂」。
- **回响（Echoes）**：新可收集物品，藏匿于古代遗迹各处。这些小小的光点常被牧场主用作装饰，来源仍是谜。每天可在遗迹的许多角落找到，或用资源采集器提取。
- 新增成就
- 新增 6 个装饰装置（deco gadgets），采用古代遗迹的漂亮美术
- 新增 12 个藏宝球——「去寻宝吧！」
- 设置项改名：「史莱姆质量（Slime Quality）」改为「模型质量（Model Quality）」，「水质（Water Quality）」改为「着色器质量（Shader Quality）」，以更好地反映这些设置的实际用途（官中见存疑 4）
- 进食（尤其最爱食物）对史莱姆躁动的安抚效果增强
- 大型猎猫史莱姆躁动到一定程度会恢复狂暴形态——小心！
- 猎猫结晶与水晶结晶价格上调，与量子结晶看齐——三种史莱姆现代表「第四档」难度
- 部分 CPU 效率相关项改进
- 草丛网格渲染效率改进——「没错，在 Monomi Park 连草都是高效的。」
- 输入库版本更新（与手柄内部机制相关）
- 水滴结晶不再被牧场交易所请求或作为奖励（原文 "not longer" 系笔误，应为 no longer）

**修复**：进入又离开某区域后音乐偶发卡住继续播放 / 吸取水果蔬菜时若在其仍振动时停手，仍会导致其脱落 / 从地里吸取蔬菜的相关 bug / 偶发可以隔墙吸取物品 / 放在展示台上的焦油怪会迅速逃走（「也许这根本不是 bug——深层来看，焦油怪只是真的很害羞」）/ 蜂蜜史莱姆与蜂蜜结晶未被正确计入牧场交易所 / 史莱姆嘴巴颜色显示异常

> 结尾：官方祝大家享受新更新，期待听到大家在古代遗迹的冒险故事。

## v0.5.1：更好的家园&巨型史莱姆更新（2017-04-18）

> 官方定性：Better Homes and Gordos Update——一批旨在改善牧场体验、提供大额新币消耗渠道（newbuck sink）、并加入新剧情元素的功能。

**7Z奖励俱乐部（The 7Zee Rewards Club）**——新功能，奖励成功牧场主的独特奖励。第 7 天中午起会收到 7Z集团介绍奖励俱乐部的星际邮件，**必须阅读该星际邮件才能解锁俱乐部**。每解锁一级花费递增的新币，对应一份独特奖励——多为彰显你在本作世界中成就的「荣誉之物」，包括牧场视觉升级、配色自定义、史莱姆玩具等；最高等级奖励需巨额新币。官方特别说明：这些奖励本意就是贵（尤其是最后三分之一），但不想让绝大多数玩家完全够不着——附论坛帖邀请玩家反馈价格，「如果社区强烈表态，价格完全可能在后续补丁中调整。」

- **调色包（Chroma Packs）**：通过 7Z奖励俱乐部获得的配色自定义物品，约占奖励总数一半。解锁后牧场小屋侧面会出现调色包站；每解锁一套新调色包，即可免费、不限次数地将其分配给牧场小屋、牧场科技（ranch tech）与真空枪。最稀有的调色包只有达到俱乐部末尾等级才能获得。
- **史莱姆玩具（Slime Toys）**：给史莱姆玩耍的玩具，像音乐盒一样安抚其躁动。玩具店通过 7Z奖励俱乐部解锁，供应基础玩具，更高级选项在更高奖励等级解锁。史莱姆靠近玩具时躁动降低——很适合丢进牧栏；每只史莱姆有「最爱玩具」，安抚效果更强。效果与牧栏的音乐盒升级叠加，但不与其他玩具叠加；多玩具在旁时史莱姆总是获得最优加成，可以放心混搭。
- **霍布森与家书（Hobson and Letters from Home）**：新剧情元素。碧翠丝牧场前任主人霍布森·推格斯（Hobson Twillgers）留下的日志散落世界各地，提供他的背景故事、偶尔的实用提示与观察。此外会偶尔收到凯西（Casey）的星际邮件——凯西是碧翠丝留在地球上的重要之人。官方说明：本次更新阅读量不小，但凯西与霍布森的故事都将在未来更新中讲完。
- **码头（The Docks）**：丰茂原野后方的新牧场扩张——淡水池塘与瀑布、四个空牧场设施、美丽海景，还有一堆可用来网住乱跑史莱姆的渔网。外加一个「秘密特性……」
- **巨型史莱姆诱捕器（Gordo Snares）**：新系列史莱姆科技装置，用来捕捉自己的巨型史莱姆！放置后把食物射进诱捕器当诱饵，运气好（且有耐心）就能诱到想要的巨型史莱姆。这些巨型史莱姆撑爆时会掉落一些奖励，但官方预感大多数人会用诱捕器弄几只大伙伴养在牧场。更高级的诱捕器将在未来更新推出。

**其他功能**：
- 新增回响网装置，可随时间自动收集遗迹里的回响——藏在遗迹某处藏宝球内
- 牧栏自动喂食器升级现提供 3 档速度，通过喂食器上的按钮切换
- 超级储槽扩容（Tank Booster Ultra）现于 7Z奖励俱乐部深处解锁——每个真空储槽可存 100 单位！
- 星际邮件新增未读通知，显示还有多少封未读（「希望它不会像现实中你盯着的那封一样让人焦虑——提醒你该回邮件，而不是读本作更新日志」）
- 鸡圈加高围墙升级后的外观更明显
- 快速连续制造多个装置时的卡顿减轻
- 结晶收集器的手动按钮现在有动画了（「我知道。这更新日志把重磅消息埋得真深。」）
- 新增几个与 7Z奖励俱乐部相关的成就
- 遗迹音乐曲目换用更高音质版本以去除音频杂音（「或者也可以说，我们从古代遗迹搞了些文物来。噢——」）
- 星际邮件界面视觉改进与可读性提升
- 采集器稀有资源掉率翻倍

**修复**：特别躁动的大型猎猫史莱姆响应驯兽铃后立刻再次狂暴 / 大型辐射喵喵与大型量子喵喵史莱姆的嘴巴 / 大型辐射猎猫与大型量子猎猫史莱姆的眼睛 / 部分采集器产量略低于预期 / 火山岛上柱子的贴图 / 装置制造界面滚动问题 / 大型量子水晶史莱姆不追结晶 / 音乐偶发莫名切回牧场曲目（「不骗你，是鬼干的」）/ 睡觉期间史莱姆有时没吃东西的问题 / 粗体文字不变粗 / 牧场交易所邮件里碧翠丝姓氏拼写错误 / 丰茂原野几座山的位置 / 静止的岩石史莱姆有时不伤害玩家 / 狂暴史莱姆偶发能把物品穿过牧栏墙射出

> 结尾：官方预告下一大型更新「玻璃荒漠（The Glass Desert）」——全新挑战、更多史莱姆、超大探索区域！另宣布官方周边开售（forfansbyfans 商店）。
