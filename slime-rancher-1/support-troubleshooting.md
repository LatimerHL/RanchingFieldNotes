## 一、常见问题（FAQ）

### 1. 无人机似乎不执行任务
- 如果无人机任务目的地的储物空间已被它负责搬运的物品**堆满**，无人机会停止执行全部任务
- 发现无人机不干活且水充足时，优先检查目的地是否已满

### 2. 难以找到泥球
- 某些情况下，泥球会从荒蛮群岛上消失
- 建议回到牧场小屋休息后重新查看，可能需要多次，泥球会重新出现

### 3. 控制器故障排除指南（Steam）
- Steam 上控制器失灵时，尝试切换控制器配置支持：
  Steam → 设置 → 控制器 → 通用控制器设置 → 勾选（或取消勾选）与你所用控制器最匹配的类型
- 仍无法解决时提交工单，需提供：平台（Steam、Humble 等）、操作系统（Windows/Mac/Linux）、控制器类型、问题描述；如能提供控制器驱动（或是否为系统预装驱动）更佳

### 4. 暂停后游戏冻结/无法检测到控制器（Xbox Series X）
- 已知问题：从暂停恢复后控制无响应，游戏可能看似冻结
- 解决办法：切换到另一个 Xbox 账户启动游戏，再切回原账户
- 建议使用「保存并退出」而非暂停来避免此问题

### 5. Steam Link 上的控制不正确/无效
- 与多数游戏一样，本作并非为触摸屏设计，官方目前不支持触摸游玩；Steam 建议连接手柄游玩，官方也赞同
- 执意使用触摸可参考 Steam 官方关于修改控制的文档（KB 4022-PFJX-8276）

### 6. 无法打开地图（Xbox）
- 部分玩家回归游戏后发现无法打开地图，与 1.3.1b 更新中的一项改动有关
- 多数情况重置控制器默认设置即可解决：选项 → 游戏手柄（RB 键切换）→ 还原默认设置（A 键确认）
- 极少数情况需额外操作：先进入「地图」选项用 A 键开始按钮重分配，将地图功能分配到左方向键，再连续两次「还原默认设置」清除错误绑定并恢复地图至右方向键

### 7. 本作会添加多人模式吗？
- 不会。游戏为单人体验设计，加入多人需要大幅重做底层架构（游戏物理模拟与市面上其他游戏完全不同）
- 开发大部分由两人完成，早期就决定了单人路线；数百只启用物理模拟的史莱姆在多个客户端间同步是极难解决的问题
- 官方正式声明：本作是单人游戏，未来也不会有多人模式计划

### 8. 最低系统配置要求
| | Windows | Mac | SteamOS + Linux |
|---|---|---|---|
| 操作系统 | Windows 7 (SP1)+ | OSX 10.11+ | Ubuntu 12.04+ 或同等 |
| 处理器 | 2.2GHz 双核 | 2.2GHz 双核 | 2.2GHz 双核 |
| 内存 | 4 GB | 4 GB | 4 GB |
| 显卡 | 512MB 专用显存 | OpenGL 3.2 兼容，512 MB 显存 | OpenGL 3.2 兼容，512 MB 显存 |
| 存储 | 1 GB 可用空间 | 1 GB 可用空间 | 1 GB 可用空间 |
| 其他 | DirectX 11 | — | 声卡：ALSA 兼容 |

> 来源：官方支持中心 + Steam 商店页（2026-08 查证）。Steam 商店页三平台最低配置一致：2.2GHz 双核、4 GB 内存、512MB 显存、1 GB 可用空间（Windows 另需 DirectX 11；Linux 另需 ALSA 兼容声卡；Mac/Linux 显卡要求 OpenGL 3.2 兼容）；**商店页未提供推荐配置**——一代配置门槛低，达到最低配置以上即可流畅游玩。

低于最低配置可能遇到性能问题或完全无法运行，官方无法确保游戏运行或提供额外支持。

## 二、崩溃和冻结疑难解答

### 1. 「Unity 2019.4.29f1」错误
- 症状：启动（偶尔加载）时出现**粉红史莱姆 + 红色感叹号**，通常意味着访问冲突，可能原因：
  - **显卡驱动过期或损坏**：前往显卡制造商官网更新驱动；驱动损坏需彻底卸载重装
  - **内存耗尽**：确认至少有 4GB 内存；内存足够仍出问题，可运行 Windows 内存诊断工具检查
  - **双显卡**：Unity 处理多 GPU 有问题，可停用第二块显卡（设备管理器删除副卡驱动）
  - **副显示器**：笔记本外接显示器可能引发问题，可在显示设置中把多显示器改为「复制这些显示」

### 2. 启动崩溃（PC）
依次排查：
1. **核对配置要求**（见 FAQ 8）；笔记本双显卡建议先在 BIOS 禁用集成显卡，或在设备管理器卸载集显驱动
2. **Steam 安全模式**运行游戏，减少资源占用；关闭不必要的开机启动项（任务管理器 → 启动）
3. **禁用超频**（可能导致 Unity 问题）
4. **更新显卡驱动/操作系统**：从 NVIDIA/AMD 官网获取最新驱动；驱动损坏可用 Display Driver Uninstaller（DDU）清洁重装
5. **更新 DirectX**：运行 DirectX 最终用户运行时 Web 安装程序
6. **排查冲突软件**：全盘病毒扫描、更新处理器驱动、卸载不再使用的程序、尝试干净启动
7. **清洁安装**：详见「执行清洁重装 - PC」
8. 仍未解决：提交工单，附上问题描述（崩溃发生在启动/加载/游戏内？冻结还是报错？）、DxDiag 信息和 Player.log

### 3. 无法启动 - 多显示器
- 已知问题：本作无法在副显示器上启动
- 解决：关闭或拔下副显示器，从主显示器启动游戏后再重新连接；优先使用副显示器可设置「复制这些显示」

### 4. 游戏时崩溃（PC）
- 多数崩溃报告与系统级内存泄漏有关，建议：
  1. 全盘病毒扫描（粗糙编写的病毒可能锁定系统资源）
  2. 禁用超频
  3. 更新显卡与处理器驱动
  4. 卸载不再使用的程序（后台进程占用资源导致冲突）
  5. 关闭除杀毒软件外的开机启动项
  6. 游戏画面设置中打开垂直同步并关闭阴影
- 仍崩溃则提交工单并附 Player.log 与 DxDiag

### 5. 寻找 DxDiag 文件
- 游戏停止响应且 Player.log 无崩溃信息时，用 DxDiag 排查
- 步骤：搜索并运行 DxDiag → 加载完成后点「保存所有信息」→ 将 DxDiag.txt 附在工单中

### 6. 寻找 Player.log 文件 - PC
- 路径：`%appdata%/../LocalLow/Monomi Park/Slime Rancher`（即 `C:\Users\[用户名]\AppData\LocalLow\Monomi Park\Slime Rancher`）
- 其中 Player.log 与 Player-prev.log 包含游戏期间的问题信息，附在工单中可帮助快速定位

### 7. 寻找 Player.log 文件 - Mac
- 访达 → ⌘+Shift+G 前往文件夹 → 输入 `~/Library/Logs/Monomi Park/Slime Rancher/Player.log`

### 8. 加载时卡死且客户端最小化（Microsoft Store 版）
- 症状：客户端无限加载，一交互就最小化
- 检查是否有**登录弹窗**（其他窗口遮挡时不易发现，建议先关闭/最小化其他窗口）
- 与登录弹窗无关时，可尝试**以管理员身份运行**，或直接从安装文件夹打开游戏

## 三、保存文件问题和疑难解答

### 1. 数据损坏错误（PS4）
- 先到加载画面确认文件是否被游戏判定为损坏；未明确显示损坏时可尝试：
  1. 将存档复制到 PSN 或 U 盘
  2. 删除 PS4 上的本地存档
  3. 可选：卸载游戏（无法新建存档时执行）
  4. 重建 PS4 数据库（安全模式）解决潜在驱动器问题
  5. 重装游戏并将存档复制回来
- 仍失败可联系 PlayStation 支持考虑高级选项

### 2. 「无法读取名为 [存档名] 的存档文件」
- 常见原因：更新后模组加载器或特定模组失效，依赖模组的存档无法加载
- 解决：重装模组加载器与模组；或等待模组作者更新兼容最新版本
- 注意：**被模组修改过的存档官方无法挽回**，建议安装模组前先备份存档
- 严重时可能连新游戏都无法创建，需彻底重装（见「执行清洁重装 - PC」）

### 3. 加载存档时游戏假死/冻结
- 加载较大的存档时游戏可能停止响应——多数情况只是加载画面卡住，后台仍在读取存档
- 完全关闭其他应用/游戏可缩短等待；数分钟后仍无法加载则提交工单，说明等待时长与系统信息

### 4. 我能在不同平台之间转移存档吗？
- **主机平台**：只能通过各主机官方提供的方法在平台间转移
- **PC（Windows/Mac/Linux）**：可互相转移；注意目标平台的游戏版本**不得早于**创建存档时的版本
- **微软账户存档**（Xbox / Microsoft Store 版）：可通过云服务在两者间访问，但**不能**转移到其他平台
- 游戏会保留存档的多个版本（可用于回退存档点）；跨平台转移只需最新时间戳的文件
- Steam 云同步开启且多台电脑游戏时，会自动用云端最新存档覆盖本地
- **存档位置**：
  - Windows：`C:\Users\[用户名]\AppData\LocalLow\Monomi Park\Slime Rancher`
  - Mac：`Macintosh HD/Users/[用户名]/Library/Application Support/Monomi Park/Slime Rancher`
  - Linux：`.config/unity3d/Monomi Park/Slime Rancher`

### 5. 在新系统上下载游戏后存档不见了
- 存档存储在**本地**，未开启云存档时它们仍留在旧系统上
- 按上述存档位置找到文件，手动复制到新系统即可

## 四、购买和安装帮助

### 1. Steam 上无法安装/更新本作
- 症状：安装时提示「Internet 连接不可用」和/或「内容配置不可用」；或 0 MB 更新无法完成（官方确认非自身问题，其他 Steam 游戏也有类似报告，建议联系 Steam 支持）
- 有效解决方法：删除 `appmanifest_433340.acf` 文件后重启 Steam（该文件记录安装状态，删除后 Steam 会在重装时重建）：
  1. Steam 库中找到本作 → 右键 → 管理 → 浏览本地文件
  2. 在地址栏进入上一级 `steamapps` 文件夹
  3. 删除 `appmanifest_433340.acf`，重启 Steam
  4. 重新下载游戏到同一位置

### 2. 从官网购买但未收到游戏
- 官网「立即购买」实际通过零售商 **Humble** 完成交易
- 使用 [Humble 的 Resender 工具](https://www.humblebundle.com/resender) 通过邮件获取新密钥（**必须使用购买时相同的邮箱**）
- 进一步协助可联系 Humble 支持团队

### 3. DLC 不显示/无法加载（Steam）
1. 游戏主菜单 → 「管理 DLC」→ 检查 DLC 是否显示已安装
2. 已安装：进游戏到牧场小屋查收 DLC 的星际邮件，然后去找那些风格皮肤（时尚舱）吧
3. 未安装：Steam 库右键本作 → 属性 → DLC 选项卡 → 勾选安装；此处不显示则联系 Steam（可能未在此账户购买）
4. 已勾选仍无效：取消勾选 → 重启 Steam → 重新勾选
5. 注意：**DLC 不适用于共享的 Steam 账户**

### 4. 如何下载专属 DLC - Xbox One
- 商店下载：Microsoft Store → 打开本作的商店页 → 附加内容中下载 DLC 包 → 「我的游戏和应用」→ 管理游戏 → 准备安装
- 游戏内下载：标题画面或牧场小屋 → 「管理 DLC」→ 选择「在商店中浏览」→ 下载安装 → 回游戏确认显示「已安装」
- 使用：新牧场主需先解锁相关里程碑——**调色站**在 7Z 奖励俱乐部中解锁，**风格皮肤（时尚舱）**需在实验室解锁史莱姆科技后可用

### 5. 如何下载专属 DLC - PS4
- 商店下载：PS Store → 打开本作的商店页 → 追加内容中下载安装 DLC 包
- 游戏内下载：标题画面或牧场小屋 → 「管理 DLC」→「在商店中浏览」→ 下载安装 → 回游戏确认「已安装」
- 使用：同 Xbox 版，需先解锁调色站（7Z 俱乐部）与时尚舱（实验室史莱姆科技）等里程碑

### 6. 从官网购买但无法更新
- 官网「立即购买」实际通过 Humble 购买
- 更新方法：使用 Humble 的 Resender 工具（同一购买邮箱）获取最新安装程序并运行

### 7. 执行清洁重装（PC）
- 使用模组后出现持续问题时，可能需要清除全部游戏相关文件夹：
  1. 找到 LocalLow 文件夹：任意文件夹地址栏输入 `%appdata%/../LocalLow/` 回车
  2. 找到 Monomi Park 文件夹，重命名（如「Monomi Park Backup」）
  3. 按购买平台正常卸载本作
  4. 重装并运行，确认问题是否解决
- 可选：重装后从备份文件夹把 `.sav` 存档复制回 LocalLow 恢复进度；若问题复现则删除这些存档

## Xbox One 版常见问题（游戏内官方 FAQ）

- **会有 Xbox 成就吗？**：本作结束测试正式发售时即开启 Xbox 成就系统，届时所有已获得的成就都会立即体现到 Xbox 成就系统中
- **PC 版和 Xbox One 版内容是否相同？**：目标是让两个版本保持同步；但考虑到 Xbox 版本认证时间，两个版本的更新时间可能稍有不同
- **之后有什么新内容？**：官方在开发新区域、新型史莱姆以及史莱姆科技的全新功能（公告见 slimerancher.com/roadmap）
