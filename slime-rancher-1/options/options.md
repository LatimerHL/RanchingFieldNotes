# 游戏选项（Options / Settings）

> 来源：游戏内 ui.txt（官方简体中文）+ 游戏机制说明
> 版本：Slime Rancher 1

选项菜单可从主菜单或暂停菜单进入，分为**图形、音频、控制、其他**四组。

## 图形（Graphics）

| 选项 | 说明 | 用途提示 |
|------|------|----------|
| **整体画面质量**（Master Graphics Quality） | 预设档位：最低 / 低 / 默认 / 高 / 非常高 / 自定义 | 整体控制阴影、纹理、特效等渲染质量；**配置较低或掉帧时调低可显著提升流畅度**；「自定义」可单独微调（部分平台） |
| **视野**（Field of View） | 第一人称视角宽度调节 | 数值越大视野越宽、可见范围越大，但边缘画面会拉伸变形；**容易晕 3D 的玩家可适当调大视野**缓解不适 |
| **分辨率**（Resolution） | 显示分辨率，格式 `宽x高 @ 刷新率Hz` | 越高越清晰、越吃性能；切换后弹出「是否保留这些设定？」确认（若画面异常可选择还原） |
| **关闭视角晃动**（Disable Camera Bob） | 开关：关闭行走/跑动时镜头的上下晃动 | 晃动模拟真实步态，但**易晕动症玩家建议开启此选项**（关闭晃动） |

**自定义画质档位的详细设置**（整体画面质量选「自定义」后可单独调节）：

| 设置 | 说明 |
|------|------|
| 环境光遮蔽（Ambient Occlusion） | 物体接触处的阴影细节 |
| 抗锯齿（Antialiasing） | 边缘平滑，可选 2x/4x/8x 多重采样 |
| 辉光效果（Bloom） | 发光物件的辉光特效 |
| 光照效果（Lighting） | 全局光照质量 |
| 模型质量（Model Detail） | 史莱姆与场景模型细节 |
| 颗粒效果（Particles） | 粒子特效数量与质量 |
| 阴影效果（Shadows） | 阴影质量 |
| 纹理质量（Textures） | 贴图分辨率 |
| 着色器质量（Water Detail） | 水体着色器质量 |
| 垂直同步（VSync） | 画面撕裂时可开启；官方崩溃排查建议开启 |
| 全屏（Fullscreen） | 窗口/全屏切换 |
| 过扫描调整（Overscan） | 显示边界调整（主机） |

## 音频（Audio）

| 选项 | 说明 |
|------|------|
| **主音量**（Master Volume） | 所有声音的总音量 |
| **音乐音量**（Music Volume） | 背景音乐音量（各区域主题曲、收音机音乐等） |
| **音效音量**（SFX Volume） | 游戏音效音量（真空枪、史莱姆叫声、环境音等） |

## 控制（Controls）

| 选项 | 说明 | 用途提示 |
|------|------|----------|
| **鼠标灵敏度**（Mouse Sensitivity） | 整体视角转向灵敏度 | 手感过快/过慢时调节 |
| **视角左右操作灵敏度**（Look Sensitivity X） | 水平方向（左右）视角灵敏度 | 与垂直方向分开调节 |
| **视角上下操作灵敏度**（Look Sensitivity Y） | 垂直方向（上下）视角灵敏度 | 部分玩家习惯上下更慢一些 |
| **手柄设置**（Gamepad Settings） | 手柄按键重映射（「更改设定」） | 主机/手柄玩家可自定义按键绑定；游戏支持全方位手柄支持 |

**更多控制/画面设置：**

- **鼠标的视角上下操作反转**（Invert Mouse Look Y）与**手柄视角上下操作反转**（Invert Gamepad Look Y）：反转垂直视角方向
- **关闭鼠标视角平滑**（Disable Mouse Look Smoothing）：关闭视角平滑，可减少拖拽感
- **关闭手柄/操作杆输入**（Disable Gamepad）：官方标注"可能修复视角转动问题"
- **死区**（Deadzone）：手柄摇杆死区调节
- **按住冲刺**（Sprint Hold）：冲刺改为按住而非切换
- **切换摇杆**（Swap Sticks，PS4 同）：交换手柄左右摇杆功能
- **打开持续吸取**（Lock Vac）：真空枪持续吸取开关
- **最小平行显示**（Minimal HUD）：简化界面显示
- **手柄断开提示**：Xbox/UWP 手柄断开时游戏会暂停并提示重新连接

## 其他

| 选项 | 说明 | 用途提示 |
|------|------|----------|
| **新手指南**（Tutorials） | 显示全部 / 仅显示高级 / 禁用所有 | 控制游戏内教程弹窗：新手选「显示全部」，老玩家可「仅显示高级」或「禁用所有」减少打扰 |
| **语言**（Language） | 界面语言切换 | 官方支持简体中文 |
| **触屏**（Touch，移动端） | 移动端专用选项组 | Android/iOS 版（Playdigious 发行）额外提供触屏相关设置 |

## 存档与自动保存

- 游戏会**自动保存**（界面显示自动保存图标提示）
- 若存档文件无法读取，游戏会询问是否尝试读取**较早的自动存档**；自动存档也无效时提示无法读取
- 相关：`../support-troubleshooting.md`（存档问题排查）
