# 基本玩家控制（Basic Player Controls）

> 来源：游戏内《史莱姆百科》- 教程选项卡
> 条目ID：basics
> 版本：Slime Rancher 1

## 简介
快动起来吧。

*Get a move on.*

## 操作说明（键鼠）
**W**：向前移动
**A**：向左移动
**S**：向后移动
**D**：向右移动

**Shift**：冲刺（消耗能量）

**空格**：跳跃（如果有喷气背包，按住即可使用）

**E**：执行行动（出现信息提示时）

**原文参考：**

> **W**: Move forward 
> **A**: Move left 
> **S**: Move backward 
> **D**: Move right 
> 
> **Shift**: Sprint (uses energy) 
> 
> **Space**: Jump (hold to use jetpack, if available) 
> 
> **E**: Interact (when prompted)

## 操作说明（手柄）
**左摇杆**：移动

**按住左摇杆**：冲刺（消耗能量） 

**A**：跳跃（如果有喷气背包，按住即可使用）

**X**：执行行动（出现信息提示时）

**原文参考：**

> **Left Stick**: Move
> 
> **Hold Left Stick**: Sprint (uses energy) 
> 
> **A**: Jump (hold to use jetpack, if available) 
> 
> **X**: Interact (when prompted)

## 操作说明（PlayStation）
**左摇杆**：移动

**L3**：冲刺（消耗能量）

**X**：跳跃（如果有喷气背包，按住即可使用）

**□**：执行行动（出现信息提示时）

**原文参考：**

> **Left Stick**: Move
> 
> **L3**: Sprint (uses energy) 
> 
> **cross button**: Jump (hold to use jetpack, if available) 
> 
> **square button**: Interact (when prompted)

## 操作说明（触屏/移动端）

移动端版本（Android/iOS）的触屏操作，`<xxx>` 为触屏界面控件：

<move>：移动

<sprint>：冲刺（消耗能量）

<jump>：跳跃（如果有喷气背包，按住即可使用）

<interact>：执行行动（出现提示时）
