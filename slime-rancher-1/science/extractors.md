# 采集器（Extractors）

> 来源：游戏内《史莱姆百科》- 史莱姆科技选项卡
> 条目ID：extractors
> 版本：Slime Rancher 1

## 简介
大自然中蕴藏着各种宝藏。

**原文参考：**

> Nature is a treasure hoarder.

## 描述
采集器是一种特殊的史莱姆科技装置，在其他种类装置的制造上起着至关重要的作用。采集器包括钻机，泵机，以及蜂房三种。

把采集器配置在建造点后，它就会开始工作，随时间推移从周围收集资源。当收集满资源后，就能把它清空取出资源。最高级的采集器在最终报废前，可以重复多次这个采集过程。

如果放置在适当区域，每种采集器都可以获得独特的资源：
泵机可以在干涸岩礁开采出特殊资源。
钻机可以在靛蓝采石场开采出特殊资源。
蜂房可以在被苔岛获取特殊资源。
所有的采集器都可以在玻璃荒漠获取特殊资源。

**原文参考：**

> Extractors are a special class of Slime Science gadgets that are essential for building all other   types of gadgets. Extractors include drills, pumps, and apiaries.
>   
>   Once placed on a build site, an extractor will begin working, collecting resources from the environment over time.   Once it is full of resources, an extractor can be emptied. The best extractors can repeat this cycle multiple times   before they finally break down.
>   
>   Each extractor can find exclusive resources if used in the correct zone:
>   Pumps can find a special resource in the Dry Reef.
>   Drills can find a special resource in the Indigo Quarry.
>   Apiaries can find a special resource in the Moss Blanket.
>   All extractors can find special resources in the Glass Desert.

### 制造材料与周期（fandom）

- **新手泵机**：1 周期（每周期 12 小时）；粉红结晶×10 + 喵喵结晶×6 + 炸弹结晶×3
- **高级泵机**：3 周期；粉红×20 + 喵喵×12 + 炸弹×6
- **专家泵机**：6 周期（制造器描述写 9，实际 6）；粉红×25 + 炸弹×18 + 旋风×10
- **深渊泵机**：12 周期；粉红×25 + 炸弹×20 + 旋风×15（7Z 秘密泵机）
- **新手钻机**：1 周期；粉红×10 + 岩石×6 + 辐射×3
- **高级钻机**：3 周期；粉红×20 + 岩石×12 + 辐射×6
- **专家钻机**：6 周期；粉红×25 + 辐射×18 + 马赛克×10
- **泰坦钻机**：12 周期；粉红×25 + 辐射×20 + 马赛克×15（7Z 秘密钻机）
- **新手蜂房**：1 周期；粉红×10 + 荧光×6 + 蜂蜜×3
- **高级蜂房**：3 周期；粉红×20 + 荧光×12 + 蜂蜜×6；**设计图需在购买新手蜂房设计图 5 天后解锁**
- **专家蜂房**：6 周期；粉红×25 + 蜂蜜×18 + 藤蔓×10
- **皇家蜂房**：12 周期；粉红×25 + 蜂蜜×20 + 藤蔓×15（7Z 秘密蜂房）

注：所有采集器均为 12 小时/周期；安装无冷却。
## 设计图获取途径（fandom）

- **新手泵机/蜂房**：建造者商店 500 新币（实验室后立即）；**新手钻机**：购买实验室后自动解锁
- **高级泵机/蜂房**：购买新手设计图 5 天后 1,500 新币；**高级钻机**：购买实验室 5 天后 1,500 新币
- **专家钻机/泵机/蜂房**：玻璃荒漠紫色藏宝球（需藏宝球破解器 III）；不是建造者商店的延时解锁项目。专家泵机对应玻璃荒漠第 20 个藏宝球；其配方为粉红结晶×25、炸弹结晶×18、旋风结晶×10。
- **泰坦钻机**：7Z 23 级（累计 576,500 新币）；**深渊泵机**：7Z 24 级（726,500）；**皇家蜂房**：7Z 25 级（876,500）
