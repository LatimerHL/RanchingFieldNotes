## v0.1.2：补丁 0.1.2（2022-11-15，官方 PST；北京时间 2022-11-16）

> 官方定性：包含 bug 修复与一部分平衡、体验上的变化，**不是**主要内容更新；官方同时预告不久后会向社区说明二代未来内容更新的规划。（原文引言：Turning the tide in the war against chickens.）

**变化**：
- 显示设置中新增调整伽马值与亮度的选项
- 增大鼠标灵敏度范围
- 放慢鸡圈外鸡的繁殖速度，防止鸡泛滥成灾
- 降低温室中的动物数量上限，以移除已经泛滥的鸡群
- 对棉兔史莱姆的跳跃作了调整，减少它们跳出牧栏的倾向，尤其是附近有食物时；官方表示会持续关注这一问题并欢迎反馈
- 调整了许多装饰装置的成本：结晶成本提高，史莱姆科技材料成本降低
- 调整水槽的成本，让它在游戏流程中可以更早制作出来

**修复**：
- 各种拼写错误已修正，另有一些是故意留下的——鲍勃（BOb）本来就是这样说话的好伐？
- 调整并更正了制作人员名单中的名字（官方致歉）
- 修复碧翠丝有时会掉穿地面的问题
- 修复玩家明明拥有必要的升级组件、却无法提升某些真空枪升级等级的问题
- 修复长时间游玩游戏后无法收集某些资源的问题
- 修复导致焦油怪比预期更危险的 bug

> 梗备注：标题引言「扭转与鸡的战争局势」、修复项里「故意留下的拼写错误 / 鲍勃本来就这么说话」均为官方玩梗，按原意保留
