## v1.1.0：玩具上新&优化调整（2025-12-03，官方 PST；北京时间 2025-12-04）

> 官方定性：正式版（v1.0.0）之后的又一次内容更新，为史莱姆补齐全套史莱姆玩具、加入更多装置与装置变体，并根据玩家反馈做多项体验调整；官方开场以「巨型史莱姆级感谢」「甜心菜涨大三倍」等玩梗致谢社区。

**更新概览**：
- **玩具人人有份**：为每一种史莱姆补齐全套专属玩具；大多数玩具会降低史莱姆的烦躁值，但有些特别玩具会带来古怪有趣的效果，把合适的玩具放进史莱姆牧栏试试看
- **暗影罐**：玩家现可在灰色迷宫各处找到暗影罐，砸开就会释放出一群暗影史莱姆；也可以更具创意地把它们带到别处，设法让收益最大化
- **更多装置与装置变种**：用更丰富的装置与变种菜单自由定制温室和彩虹岛，拓展玩法与装饰风格——为最爱的史莱姆制造机械狂欢，或打造一片纯美天堂
- **体验优化**：从光照全面打磨、室内外过渡优化，到制作界面更新等一系列升级与修复

**UI 优化**：
- 新增加载界面的动画过场效果
- 为结尾动画和制作人员名单新增「跳过」按钮
- 在基础装置上增加橙色小圆点提示，用于标记已经解锁但尚未查看的装置变种
- 加载界面现在会隐藏鼠标光标
- 当藏宝球、设计图或幽灵无人机弹出升级组件提示时，按下 F1 会直接打开史莱姆百科中对应的页面或升级条目

**体验优化**：
- 优化并打磨游戏中所有区域和分区的光照效果，使室内与室外空间之间的光照过渡更加平滑自然
- 游戏启动时新增光敏警告界面
- 为真空枪发射、喷气背包和真空枪吸入新增独立的设置开关；同时加入提示，警告玩家更改这些设置可能会导致游戏教程中的操作说明与当前设置出现不一致；设置菜单中的部分文本描述同步更新
- 新增音频设置开关：玩家现在可以选择在游戏暂停或游戏窗口未被激活时，将游戏整体静音
- 调整「新游戏」界面，现在会先引导玩家进入新游戏设置菜单，以配置基础图像设置
- 玩家现可在制造器和史莱姆百科中，对设计图和玩家升级进行「标记/取消标记」，并查看已标记的项目
- 此外，玩家在野外收集资源时，也可以查看某个制作用设计图或升级项目及其当前进度
- 新增类似金罐的暗影罐，帮助在收集暗影结晶方面遇到困难的玩家
- 改进藏宝球及其周围区域的视觉效果
- 为通讯站新增初始指示与教学提示，会在玩家首次与其交互时弹出
- 碧翠丝去购物啦！为游戏中的角色模型增加了衬衫的立体细节网格
- 对史莱姆的外观和功能做了一些小幅改进，看看你能不能发现这些细节变化
- 对部分美术资源进行了小幅优化，并重新调整了 LOD（细节层次）
- 小鸡被吃掉时新增飘散羽毛的粒子效果。真香！
- 为瀑布添加新的环境交互效果，试着往水帘里射点什么看看
- 尽情在彩虹岛上跑八百米/一千米吧，现在的体力消耗会比以前更少
- 为池塘与焚烧炉地块新增结晶收集器升级

**错误修复**：
- 「砰！」成就现会追加发放
- 怪洋葱现可被勘探无人机选为目标
- 调整勘探无人机的行为：在能量与资源容量已满的情况下，它们不再会在极短时间内收集到异常大量的结晶
- 将设置菜单中的「狂暴」开关重命名为「狂暴攻击」，以更好地体现该选项的用途（仅英语）
- 又一次把「弹性史莱姆」放逐了（官方玩梗）
- 悬空的史莱姆雕像现在会持续存在于世界中，而不会再消失不见
- 「全部标记为已读」现在会如预期那样清除项目上的小圆点提示
- 史莱姆不再会把自己从牧栏的墙里炸出去

**已知问题**：
- 在 Microsoft Store 中切换用户会导致主菜单音乐持续播放，直到重启游戏为止
- 在「新游戏」菜单中设置整体画面质量时，各项图像选项实际上不会发生改变
- 分拣器可能会导致史莱姆的物理效果异常
- 大型猎猫旋风史莱姆在隐身前会先变成纯白色
- 碧翠丝走过灰色迷宫熔岩区域的那段管道时会受到伤害
- 生态箱与奇异天空的部分区域，性能表现低于灰色迷宫的其他区域
- 在主机平台上，靠近沼泽的巨型超能史莱姆时，帧率无法达到优化水平

**展望新年**：
- 伴随本次更新，官方向 2025 年告别并迎接新的一年；玩家可以继续期待二代的后续开发，官方「乐观地」计划在 2026 年春季或夏季推出下一次更新
- 官方感谢社区的支持与灵感，并引导玩家访问二代官方帮助中心；若遇到新 BUG，先查阅已知问题页面，未列出再提交工单

## v1.1.1（2026-01-22，官方 PST；北京时间 2026-01-23）

> 官方定性：v1.1.0（玩具上新&优化调整）之后的修复补丁，含 BUG 与平衡性修复。

- 实装了一系列内存优化，解决游戏崩溃问题
- 暗影史莱姆产出的暗影结晶达到最大数量后即自动消失
- 减少了暗影罐中的暗影史莱姆数量——之前里面实在是太挤了

> 官方说明：遇到恼人的 BUG，请先查阅二代游戏已知问题（v1.1.0）页面，确认团队是否已知晓；若未列出，欢迎提交工单（https://slimerancher2.zendesk.com/hc/zh-cn/requests/new ）。
