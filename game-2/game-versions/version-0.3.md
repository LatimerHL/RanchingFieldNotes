## v0.3.0：风雨「姆」阻（2023-11-14，官方 PST；北京时间 2023-11-15）

> 官方定性：动态天气首次降临彩虹岛，同时回归两位人气史莱姆——藤蔓史莱姆与旋风史莱姆。各种气象模式首次笼罩彩虹岛，牧场主可穿行于暴雨、雷暴、虹彩花粉甚至巨大旋风之间。

**新内容概览**：
- 动态天气系统：二代现在拥有动态天气系统，玩家可在世界各地体验不同程度的雨、风、雷暴、花粉等多种天气；既可勇敢直面更恶劣的天气，也可放松下来享受温和气象下的舒适氛围
- 新增原声音乐：每种恶劣天气都配有美妙的新旋律，陪伴牧场主冒险回家的险途或追逐风暴的壮举
- 旋风和藤蔓史莱姆回归：乘着旋风在风暴中驾临、伴着藤蔓从地下冒出，这两位史莱姆已回归并加入碧翠丝的最新冒险；要在恶劣气象中仔细追查，才能捕捉这群难以捉摸的史莱姆
- 美味小食：不能让刚到手的藤蔓和旋风史莱姆挨饿——它们最喜欢的食物刺刺梨、彩色母鸡和彩色鸡仔儿也随之回归；官方提醒：饥饿的史莱姆是不开心的
- 史莱姆百科改头换面：为了让玩家更容易了解本作的世界，史莱姆百科进行了大规模改版；记得查看地图上最新的天气信息

**动态天气系统**：
- 可在区域中产生不同类型、不同强度的气象，气象之间还可能叠加，在彩虹岛上形成狂风暴雨；气象可通过地图追踪查看
- 注意触发条件：动态天气只在游戏内时间过去两天后才开始形成，且只会在已经探索过的区域内出现
- 新存档：若某区域此前已访问过一次，最快在第 3 个游戏日就可能出现天气
- 既有存档：更新后必须再经过两个游戏日，才会开始形成气象

**气象类型**：
- 风：强度不同，最终演变为风暴，可卷起旋风；有专属音乐配乐
- 雨：强度不同，最终演变为暴雨，可在地面形成水坑和瀑布；有专属音乐配乐
- 雷：强度不同，最终演变为雷暴，可致闪电从天而降；有专属音乐配乐；雷暴通常伴随暴雨发生，但并非总是如此
- 花粉：强度不同，最终可导致藤蔓在该区域生长；有专属音乐配乐
- 雪：仅限落粉峭壁，其异常寒冷的气候才能支持雪的存在
- 史莱姆之雨：官方在此处卖关子——「等一下，史莱姆之雨？哦，不是吧……」

**新增史莱姆**：
- 旋风史莱姆
- 藤蔓史莱姆

**新增资源**：

- 修复通讯站中莫奇对话的一些本地化问题

- 让靠近灰烬山谷火山时的闪电过渡更平滑（⚠️ 原文作 lightning，译文推测是 lighting 的误拼）

## 术语修正与存疑 ⚠️

1. **The Gully** ✅：官中为「陡峭岩沟」；B 站译文作「潮水池」，但「潮水池」对应的是 The Tidepools，正文已改回「陡峭岩沟」
2. **Yolky Slime / Giant Egg** ✅：B 站译「蛋黄史莱姆的蛋……显示为『巨大的蛋』」；Giant Egg 官中为「巨蛋」，正文采用官中
3. **Largo / Gordo 命名次序** ✅：官中格式为「大型〈物种〉史莱姆」「巨型〈物种〉史莱姆」；B 站译文作「剑齿蜂蜜史莱姆」「浣熊大型史莱姆」「棉兔巨型史莱姆」，正文统一改为「大型剑齿蜂蜜史莱姆」「大型浣熊史莱姆」「巨型棉兔史莱姆」
4. **Slimefall** ✅：官中为「史莱姆之雨」，正文与译文一致
5. **Vine Tangle** ✅：官中为「缠绕的藤蔓」，正文按官中表述花粉最终导致的藤蔓生长
6. **crafting resources** ⚠️：B 站译作「史莱姆科技材料」，无官中直接对照，正文按原意写作「制造资源」
7. **Come Rain or Slime** ✅：无官中标题对照，沿用 B 站译文「风雨『姆』阻」
