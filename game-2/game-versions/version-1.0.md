## v1.0.0：英雄已至（2025-09-23，官方 PDT；北京时间 2025-09-24）

> 官方定性：碧翠丝的冒险在拯救彩虹岛的最后一搏中迎来激动人心的终章。二代团队终于能与各位分享碧翠丝冒险故事的高潮部分以及彩虹岛的最终命运；在本更新中，玩家将深入探索灰色迷宫的最深处，寻找威胁彩虹岛乃至整个致远牧星的力量源头，并以全新装置、真空枪升级和牧场主梦寐以求的量子无人机武装自己。

**更新概览**：
- **灰色迷宫核心区域**：跟随碧翠丝前往神秘灰色迷宫的核心地带，发现一片引领玩家前往彩虹岛棱镜核心的全新区域；这片废墟谜题重重，每个角落都可能揭开迷宫中埋藏的秘密；探索时也要步步为营——如同每位英雄的旅程，危险正等待着你
- **属于牧场主们的量子无人机**：广受喜爱的嗡嗡小蜜蜂从一代回归，并经量子迭代；这款可爱且富有表现力的助手无人机经过升级，能更好地协助玩家在温室中管理牧场、在野外收集资源。官方玩梗：奇怪的是，这种科技本不应该实现，除非……
- **能量十足的新史莱姆**：灰色迷宫深处将出现一种极速又时尚的新史莱姆；这些肾上腺素狂热分子很难被圈养，即使是老道的牧场主也得时刻保持警惕；它们很喜欢以惊人的能量爆发在任何表面弹射起步
- **丰富的牧场主升级与装置**：本次更新带来全新的真空枪升级与玩家专属升级，用于在整座灰色迷宫内探险；同时还有一系列新装置与装置变体，满足玩家在探索与装饰上的各种需求
- **呼叫所有成就党**：有耐心的玩家现在可以在 PC、PS5 与 Xbox Series X/S 上解锁成就；部分特殊成就将按既有进度追溯授予，其他成就则需玩家在游戏中再次完成特定操作才能解锁

**新内容一览**：
- **故事终章，秘密揭晓**：本次更新将带领玩家进入灰色迷宫的核心——穿越神秘生态箱，揭示通往音律秘密的隐藏通道，并在最后时刻直面怪物级的敌人；揭晓棱镜核心的秘密、拯救彩虹岛的重任落在玩家与琪琪身上；至于琪琪本人的秘密，唯有时间能告诉我们答案
- **新史莱姆**：超能史莱姆、巨型超能史莱姆
- **新食物**：涡轮土豆
- **新结晶**：超能结晶
- **神秘游戏货币**：彩虹币

**量子无人机：忙碌牧场主的好帮手**：
- 一张熟悉（但经过升级）的面孔随量子无人机一同回归；这些可爱的机器人装置能协助玩家完成放牧和资源收集任务
- 它们可在**牧场主模式**和**勘探模式**之间切换，大大提升了无人机在彩虹岛的实用性；别忘了用结晶给这些忙碌的小蜜蜂补充能量
- **牧场主模式**：放置在温室时，无人机可通过完成预设任务，实现照料史莱姆、打理园地和清理场地的自动化
- **勘探模式**：放置在野外时，无人机会负责采集彩虹岛上的各种资源；玩家可以通过全新的「量子云」库存即时取用这些收集到的资源
- 经过一天的辛勤劳作，量子无人机可能会犯困；利用**无人机站点**为它们充电、让它们稍作休息，站点也可为无人机编程并用大量结晶补充燃料；制造出的每个无人机站点都会附有一台配套的无人机

## 术语修正与存疑 ⚠️

1. **超能史莱姆 / 巨型超能史莱姆 / 超能结晶（Hyper Slime / Hyper Gordo / Hyper Plort）** ✅：官中语料库确认为**超能史莱姆**（Actor/Pedia）、**巨型超能史莱姆**（Pedia）、**超能结晶**（Actor）；B 站 1.0.0 译文作「超能史莱姆／超能巨型史莱姆」，巨型史莱姆格式已按官中改为**巨型超能史莱姆**
2. **「棱彩」与「棱镜」分工** ✅：装饰装置的 Prismatic 系列官中统一作**棱彩**（棱彩螺旋树、棱彩旋转木马、棱彩微型风车、棱彩巨型茎秆等）；而 Prisma Disruption / Prisma Stabilizer / Prisma Plort / Prismacore 等资源与区域词官中作**棱镜**（棱镜干扰、棱镜稳定器、棱镜结晶、棱镜核心）。B 站译文同样区分，未改动
3. **量子无人机与两种模式（Quantum Drones / Rancher Mode / Explorer Mode / Quantum Cloud）** ✅：官中语料库确认**量子无人机**（Pedia/UI/Achievement）、**牧场主模式**、**勘探模式**、**量子云**（全部为 PediaPage/UI），与 B 站一致
4. **无人机站点 / 量子无人机站点（Drone Station / Quantum Drone Station）** ✅：官中 UI 作**无人机站点**、百科条目作**量子无人机站点**；1.0.0 用前者、1.0.3 用后者，均按官中保留（B 站均作「无人机站点」）
5. **专家级巨型史莱姆诱捕器（Master Gordo Snare）** ✅：官中 Pedia 作**专家级巨型史莱姆诱捕器**，与 B 站一致
