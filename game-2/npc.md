# NPC 一览（二代）

> 适用：二代
> 来源：游戏内本地化文本（Rancher 表角色名、CommStation 对话、琪琪线、看护员）+ fandom（NPC 页面，SR2 相关内容）
> ⚠️ **剧透警告**：本页部分角色（琪琪、索拉、霍布森、维克多）的详细介绍涉及主线剧情，已标注【剧透】；未标注的为无剧透内容。

二代的角色体系：游戏内**没有实体 NPC 模型**，所有角色通过**通讯站（Comm Station）**联络与赠送礼物；琪琪（棱镜核心）与看护员（圣域）以全息投影 / 机器人形式在场。通讯站全部对话与赠品清单见 `ranch/comm-station.md`，看护员商店见 `ranch/caretaker.md`，琪琪全套资料见 `gigi/`。

## 碧翠丝·乐步（Beatrix LeBeau）

- **身份**：主角，彩虹岛新任牧场主（温室主人）
- **简介**：在一代的故事后，碧翠丝结束一天劳作，收到一封神秘信件与一艘空船——信中邀请她前往彩虹岛。她乘船渡过史莱姆海，发现彩虹原野上一座废弃温室（配备牧场主所需的一切），以此为家开始新冒险（开场文本见 `gigi/story.md`）。
- **关联**：全部通讯站、琪琪线与看护员互动均为她的视角
- **备注**：本作中她与地球旧友凯西（Casey）的联系不再出现（凯西线为一代内容）

## 琪琪（Gigi）

- **身份**：棱镜核心区域的联络人，以全息投影出现，经营兑换站（棱镜结晶兑换）
- **简介**：碧翠丝在灰色迷宫深处遇见的神秘人物。她了解彩虹岛与棱镜核心的许多秘密，委托碧翠丝收集棱镜结晶研发装置、寻找隐藏区域，是主线任务的关键指引者。
- **关联**：`gigi/exchange.md`（兑换站交易）、`gigi/projector-dialogues.md`（投影仪对话；对话组：GigiCore / GigiIntro / GigiHubIntro / GigiOutsideGold / GigiRewardsKiosk）、`gigi/research-drones.md`（调研无人机记录：GG.Log 琪琪日志 23 条 + GG.Archive 隐藏档案 19 条，密钥解锁）
- **备注**：全名琪琪·推格斯-韦斯特（Gigi Twillgers-West）
- > ⚠️ **【剧透】完整故事线**：琪琪的真实身份（来自未来的少女）、与索拉·韦斯特和霍布森·推格斯的关系、棱镜核心灾难的真相、时间旅行与结局——见 `gigi/story.md`（含剧透警告），本页不再展开。

## 维克多·亨福里（Viktor Humphries）

- **身份**：科学家，通讯站联络人之一
- **简介**：彬彬有礼但效率至上（fandom：自称职业史莱姆牧场主、史莱姆科学家与业余音乐家；因研究很少出门）。通过通讯站联络并赠送装置设计图与传送器。
- **赠品**：返程传送点、温室椅子/桌子、大风车/小风车、彩带/围巾流苏、风向袋、注意/好奇/医疗站/谨慎旗帜、蓝/灰/粉红/紫色传送器、辉光投影仪
- **关联**：`ranch/comm-station.md`（对话 + 赠品清单；对话线见「维克多·亨福里」节：ViktorIntro / ViktorStoryCipher1-4 / ViktorGift / ViktorDeflect）
- **后日谈（1.3.0）**：片尾后新增通话 ViktorPostGameLine01-08——琪琪离开迷宫后**主动联系**他，两人**计划见面**（琪琪让他「餐桌留位」）；他仍为棱镜核心真相动容，并确认辉光投射器设计图确实帮到了琪琪
- **备注**：官方译名**亨福里**（Rancher 表）
- > ⚠️ **【剧透】**：他收到的"来自某种人工智能程序的神秘代码"正是伪装成 AI 的琪琪（用于检验他的可信度与科学能力）；他完成的**辉光投影仪**（Radiant Projector）设计图是进入灰色迷宫的关键道具（详见 `gigi/projector-dialogues.md` 的 GigiSecret 组）。

## 莫奇·迈尔斯（Mochi Miles）

- **身份**：顶级牧场主（fandom：亿万富翁 Tatsuya Miles 之女，经营结晶市场）
- **简介**：傲慢毒舌的富家女（一代设定延续）。2 代中通过通讯站与碧翠丝联络并赠送礼物。
- **赠品**：精炼链接（Refinery Link）等
- **关联**：`ranch/comm-station.md`（对话见「莫奇·迈尔斯」节：MochiIntro / MochiStoryDrones1-3 / MochiGift / MochiDeflect）
- **后日谈（1.3.0）**：片尾后新增通话 MochiPostGameLine01-07——禁止碧翠丝透露调研无人机情报，宣称要**自己（现在的莫奇）造出来**，抢在未来的自己之前；结尾向碧翠丝道谢

## 奥格登·奥提兹（Ogden Ortiz）

- **身份**：退休食品大亨（fandom：曾经营化学食品企业，后到致远牧星亲手种植）
- **简介**：热情爽朗，痴迷天然食物与库卡多巴果（一代设定延续）。2 代中通过通讯站联络，赠送便携工具类装置。
- **赠品**：便携水龙头、便携稻草焦油怪等
- **关联**：`ranch/comm-station.md`（对话见「奥格登·奥尔蒂斯」节：OgdenIntro / OgdenStoryRainbow1-3 / OgdenGift / OgdenDeflect）
- **后日谈（1.3.0）**：片尾后新增通话 OgdenPostGameLine01-10——震惊于「未来反噬过去」；反思自己当年是**逃避**、而琪琪选择**直面**，因此更钦佩她；请碧翠丝代向琪琪转达

## 索拉·韦斯特（Thora West）

- **身份**：资深牧场主（一代"欢迎委员会"负责人），**霍布森·推格斯的妻子**，通讯站联络人之一（资料手册 v1.2.0 确认）
- **简介**：豪爽直率的资深牧场主，赠送植物主题装饰与诱捕类工具设计图。
- **赠品**：装饰设计图（琥珀草/天蓝色草/火棘花/翡翠草/金瓣花/粉红草/粉红红树林/彩虹草/红宝石草/短棕榈/向日葵雏菊/高翠柏）、工具设计图（高级巨型史莱姆诱捕器、驯服铃铛）
- **关联**：`ranch/comm-station.md`（对话见「索拉·韦斯特」节：ThoraIntro / ThoraStoryBigNews1-3 / ThoraGift / ThoraDeflect）
- **后日谈（1.3.0）**：片尾后新增通话 ThoraPostGameLine01-07——她已是**祖母**且当妈妈很适合；与**霍布森（霍比）**一起照料**襁褓中的女儿**（即琪琪未来的母亲），把棱镜核心之谜留给下一代
- > ⚠️ **【剧透】**：2 代揭示她与霍布森·推格斯是**琪琪的祖父母**；结局中琪琪离开迷宫后与祖父母第一次团聚（详见 `gigi/story.md`）。

## 鲍勃（BOb）

- **身份**：神秘"鸡"人（说话几乎只有鸡相关内容）
- **简介**：fandom：可能是多只史莱姆堆叠穿着风衣与软呢帽伪装成牧场主（2 代里可由量子/炸弹/喵喵等多种史莱姆组成——"这一切只是巧合，鲍勃和碧翠丝一样是正常人。绝对是。"）；据称是维克多的同事。通讯站对话是加密乱码彩蛋。
- **赠品**：装饰设计图（彩虹块/彩虹丘/岩石块/岩石簇/岩石碎片/尖石/石笋簇/细洞柱）；送礼对话为加密乱码（如"亻尔女子月月友亻火亻半 / hallOO fEllowww hOomin"）
- **关联**：`ranch/comm-station.md`（对话见「鲍勃」节：BObGift21-25 / BObDeflect）
- **后日谈（1.3.0）**：片尾后新增通话 BObPostGameLine01-05——仍是乱码祝贺（「小鸡～～玩碎～～！！」）
- **备注**：一代谜团延续；原文拼写 **BOb**

## 看护员（Caretaker）

- **身份**：圣域管理员机器人（1.2.0 新增）
- **简介**：经营**看护员商店**：用辉光史莱姆产出的**彩晶**（Sprinkles）兑换商品（含圣域房间/壁龛主题）。灰色迷宫奇异天空（Impossible Sky）区域有 3 个损坏的看护员（互动显示“（已无法运作）”）。
- **关联**：`ranch/caretaker.md`（看护员对话：CaretakerSharedFeelings / CaretakerRuinedFunctionality / CaretakerANewHome 等 20+ 条，含 Caretaker* 系列与 Incidental 系列；+ 完整商品目录）、`ranch/themes.md`（圣域主题）
- **备注**：官方译名**看护员**（非护理员/看守员）
- > ⚠️ **【剧透】**：他曾是灰色迷宫众多机器人之一，是唯一既未腐烂也未离开的；其来历与棱镜核心时代相关（详见 `ranch/caretaker.md`）。

## 霍布森·推格斯（Hobson Twillgers）

- **身份**：一代主角牧场的前任主人（一代角色，2 代未直接出场）
- **简介**：2 代中仅以间接形式出现：琪琪提到迷宫与玻璃荒漠的关联，结局出现家族合影影像。
- **关联**：`gigi/story.md`、一代档案 `../game-1/npc.md`
- > ⚠️ **【剧透】**：2 代揭示他是**琪琪的祖父**；"超越时空的传送门"的建造者（玻璃荒漠），琪琪用它穿越到现代时间线；结局家族合影（霍布森、索拉与幼年琪琪的母亲）中首次亮相。
