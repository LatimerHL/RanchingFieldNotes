## 默认键位表（Tutorial 表 m.input.*）

| 操作 | 键鼠 | 手柄 |
|------|------|------|
| 移动 | W/A/S/D | 左操作杆 |
| 跳跃/冲刺 | 空格 / 按住Shift | Jump / Run |
| 真空吸取 | 按住鼠标右键 | Vac |
| 射击 | 鼠标滚轮选槽 / 按住鼠标左键 | PrevSlot / NextSlot / Attack |
| 喂食 | 鼠标滚轮 / 按住鼠标左键 | PrevSlot / NextSlot / Attack |
| 结晶市场 | 鼠标滚轮 / 按住鼠标左键 | PrevSlot / NextSlot / Attack |
| 地图 | M | OpenMap |
| 装置模式 | T | ToggleGadgetMode |

> 移动轴（手柄）：左/右、后/前；按键名官中对照见 `keys.md`。
